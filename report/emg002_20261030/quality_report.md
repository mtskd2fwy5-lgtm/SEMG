# EMG002：重新佩戴后的质量与旧模型验证

结论：滤波仍有效，采集完整；重新佩戴后旧模型的握拳、伸腕识别明显下降，且CH4存在一段持续异常。最后一段包含两种动作，已明确排除出分类评分及训练候选标签。

## 来源与标签

共 1,113,142 帧、278.2855 秒、4000 Hz。raw与最终处理波形同时保存，序号连续，无缺帧、重复、倒退、非法标签或帧尾残缺。八路均未达到数字满量程，raw最大绝对值约为满量程的 17.34%。

用户确认相较EMG001重新佩戴；本次未再次确认是否有其他采集条件变化，比较中的变化不能单独归因于位置、松紧或接触中的某一个因素。滤波码3，链路为50 Hz陷波→梳状滤波→20 Hz高通→约215 Hz低通；5–10秒全通道整数参考误差均为2 counts。

**254.27675–278.28550秒：原标签14并非纯“拇食中伸出”。用户说明先为食指＋中指＋无名指伸出，再为拇指＋食指＋中指伸出，切换时刻未知。**原BIN和解码CSV保持原标签，`label_correction.json`额外记录语义；整段不作单一手势的分类评分或监督训练。不能用算法发现的波形变化点替代人工动作真值。

主工频仍受强抑制。CH4的原始50 Hz占比低，不代表质量最好：它的宽带及低频异常增大了占比分母。谐波邻域也包含生理及背景能量，不能全部解释成纯干扰。

CH4最明显的问题在约51–79秒，尤其60.4495–65.99725秒的放松段：去边界后的100 ms RMS中位数约177.9 counts，普通静息段约9–10 counts；该段P95约302.2 counts。这不是单个边界尖峰，单纯裁掉动作首尾1秒也无法清除。第二次握拳段CH4的100 ms RMS最大约703 counts。

CH4静息0.5–20 Hz RMS约32.88 counts，较EMG001增加约27.85 dB；静息去线频20–450 Hz RMS约38.60 counts，较上次增加14.27 dB。其静息低频能量占0.5–450 Hz约42%。接触运动、局部肌肉活动、标注或硬件异常都可能参与，不能据此直接断言断路。首要检查CH4两片电极、线缆与接触稳定性，并回看该时段是否有调整或运动。

其他通道的处理后静息去线频宽带RMS变化约−2.28至+2.36 dB，整体背景较接近；本次原始低频漂移多数增加。CH6/CH8静息谐波邻域占比约6.73%/8.66%，低于上次19.30%/21.88%，但佩戴及动作过程不同，不据此认定整个模拟链路全面改善。

| 张手 | 仍以CH3为主，CH2和CH4增强；CH4中位RMS约为上次1.91倍。 |
| 握拳 | CH4增强到约1.72倍，CH1约0.78倍，CH3约0.57倍，CH6约0.66倍。 |
| 屈腕 | CH8仍明显，CH2和CH4增强。 |

说明佩戴后的幅值及空间分布确有改变；既有伸腕响应通道减弱，也有局部异常，不能只通过降低置信度门槛解决。

## 冻结旧模型测试

没有重训、没有改阈值。仅评价原五类，三个单指及组合手势均不计五类准确率。稳态去每段首尾1秒；包含边界时按窗口末端标签评分，受标注时差影响。板端回放假设零环移位、录制开始做静息校准，实际板端基线、环移位和特征相位未写入BIN。

| 模型 | EMG001稳态 | EMG002稳态 | EMG002含边界 |
|---|---:|---:|---:|
| 008/009旧浮点模型 | 98.34% | 68.31% | 64.93% |
| 多次佩戴综合浮点模型 | 98.76% | 86.35% | 81.47% |
| 当前INT8直接判决 | 97.28% | 84.28% | 79.41% |
| 当前INT8＋门控及稳定判决 | 98.35% | 84.82% | 80.44% |

| 实际动作 | 当前INT8＋原判决召回率 | 主要误判 |
|---|---:|---|
| 放松 | 100.00% | 无 |
| 张手 | 100.00% | 无 |
| 握拳 | 10.03% | 伸腕，619窗 |
| 屈腕 | 100.00% | 无 |
| 伸腕 | 73.10% | 张手，318窗 |

两段握拳分别只有约23.67%和2.48%的稳态窗口识别正确，主要被判为伸腕；两段伸腕召回约82.88%和59.27%，主要被判为张手。第一段握拳已在35.51–43.75秒识别不佳，早于最严重CH4异常，因此不能把全部下降都归因于51–79秒异常。

即使临时排除43.745–79.15975秒，只作敏感性诊断，剩余稳态准确率约90.05%，第一段握拳召回仍为23.67%。这个排除范围是观察数据后选择，不能替代完整记录正式结果。

错误的握拳预测最高分中位数仍约99；不是“置信度不够所以识别失败”。输入INT8量化无溢出截顶。历史训练特征与实际PL能量特征合同差异仍存在，本次按真实PL特征单列统计。所有冻结模型哈希保持不变，权重JSON重建MEM一致；128窗真实C推理及全流C判决参考交叉校验通过。

## 单指与组合动作

本次增加拇食、拇中、食中组合，各只有一个连续段；此前单指动作同样各一段，无法给出可靠的跨重复分类准确率。响应并非单指幅值的简单相加：例如拇食组合CH3中位RMS约58 counts，低于本次单独拇指约118 counts。这符合动作发力方式与协同变化，但尚不足以建立可靠的组合映射。

拇指、食指、中指、拇食、拇中、食中均可保留为后续扩类候选，需补多次从放松开始的独立重复和不同舒适发力。最后混合段先整体留作未定标签，不猜测切分。旧五类模型对这些动作的输出不能当作真值。

## 建议处理

1. 优先复核CH4在51–79秒的接触/线缆及真实动作，暂不作为干净样本自动纳入。
2. 重新佩戴确实暴露了泛化问题；补充腕部中立的握拳，以及伸腕的独立多轮样本，包含舒适轻度和中等发力。
3. 后续训练先统一PL与离线特征合同；本次可作冻结旧模型的跨佩戴测试，若转用于训练，则还需另留新佩戴批次测试。
4. 新指势每次回到放松再重复，不用一个长连续段切成随机窗口自证高准确率。
