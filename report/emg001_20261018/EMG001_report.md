# EMG001.BIN 数据检查报告

输入文件：`F:/EMG001.BIN`  
本次解释：**CH8 是 BIAS 输出监测通道，CH1–CH7 才是肌电采集通道。**

补充接线信息：CH8 的 `INP` 接 BIASOUT，`INN` 接 GND。以下判断按 GND 为模拟地 AGND 处理；若实际接的是 DGND，需单独更正。

## 结论

这份文件能正常读取，但如果 CH8 确实接的是 BIAS 输出，当前数据质量为 **BAD / 不适合作为 8 路肌电训练数据**：

- 文件共 44,611 帧，4 kSPS，约 11.153 s；CSV 中的采样时间间隔保持 250 µs。
- 文件中没有真正的向前丢帧，但源序号在约 44.75 ms 处从 65202 回退到 64691，出现 1 次序列重启/回退。现有解码器把这个回退按模运算显示成 65,024 个“缺帧”，不能直接按 65,024 个物理样本丢失理解。
- CH8 的范围几乎覆盖 ADC 全量程：`min=-8,388,608`、`max=8,360,234`，超过 7,000,000 count 的样本约 **51.3%**，并且约 **50 Hz** 翻转。它不是正常肌电波形，而是 BIAS 驱动/回路的强周期监测信号，并且已经发生饱和。
- CH1–CH7 没有 ADC 削顶，但 50 Hz 仍很强；原始谱中 CH1–CH6 的主峰均约 50.05 Hz。notch50 支路能降低一部分 50 Hz，但 CH1、CH2、CH4 仍有明显残留。
- CH1–CH7 的第一主成分约占 84.7%，相关系数中位数约 0.374；排除 CH8 后共模问题仍存在，但已经不能把 CH8 的饱和波形混入肌电统计。

## CH8（BIAS）波形

| 项目 | 结果 |
|---|---:|
| 中位数 | -1,201,784 count |
| 均值 | -592,851 count |
| RMS（未去除 BIAS 波形） | 6,399,547 count |
| 最小 / 最大 | -8,388,608 / 8,360,234 |
| `abs(value)>7,000,000` 比例 | 51.3% |
| 过零次数 | 981 |
| 估计翻转频率 | 约 50 Hz |

这说明 CH8 不能继续参加 MAV、门控、频谱峰值或模型输入。notch50 后 CH8 仍有约 1.32M count RMS，并保留明显的谐波/饱和痕迹，因此软件滤波不能替代正确的 BIAS 回路和输入连接检查。

当前固件把 `CHnSET` 配成增益 8；按工程记录的 VREF=4.5 V，理想差分满量程约为 ±0.5625 V。`BIASOUT→INP、AGND→INN` 会把 BIASOUT 相对模拟地的全部直流和交流直接送入 CH8 差分量程。CH8 已经大量贴近正负满量程，因此这套监测接法/增益至少处于过量程状态；仅凭 ADC 码值不能区分“BIAS 回路本身振荡”和“监测输入共模或差分量程不匹配”。

## 对工程的直接影响

当前固件和数据分析默认把 8 个通道都当作肌电通道。既然 CH8 是 BIAS 输出，后续应采用 **7 路肌电 + 1 路 BIAS 诊断** 的通道映射：

1. CH8 从动作识别输入、MAV、门控、频谱和训练数据中排除。
2. CH8 单独显示为 `BIAS MONITOR`，显示峰值、饱和比例和 50 Hz 状态。
3. SD 文件可以继续保存 8 路，但元数据必须明确 `channel_8=BIAS`，不能再称为 8 路肌电。
4. 检查 CH8 的 ADC 输入是否确实接在 BIA/Biasout 监测节点；如果 BIASOUT 只是要反馈到人体电极，不应把它作为普通肌电输入使用。
