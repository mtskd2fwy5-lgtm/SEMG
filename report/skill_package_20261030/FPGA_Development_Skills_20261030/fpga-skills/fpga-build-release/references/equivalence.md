# 数值与时序等价验证

先填写合同：输入范围/更新节拍、系数格式、位宽/符号、乘加中间位宽、舍入/截断/饱和、状态初始化、输出延迟、握手与复位。确定目标是逐位、容差还是功能等价；若允许延迟变化，按事务对齐并单独报告新延迟。

| 风险 | 有用验证 |
|---|---|
| 表达式符号或隐式位宽改变 | 正负边界、负系数、右移、累加溢出与饱和；打印中间值定位首次差异 |
| 定点滤波极限环/残余偏置 | 冲激、阶跃、满幅后长零输入；检查丢弃小数和状态更新 |
| 复用算子破坏更新次序 | 对齐输入事务，检查输出次序/有效信号；背压、重复索引与中途复位 |
| RAM 推断替代寄存器 | 读写同址语义、首读、有效位、复位和未初始化内容 |
| 共享计数或多通道分时 | 同步更新、通道隔离、参数边界和每路独立值 |
| 系数/ROM 仅行为仿真正确 | 实际综合网表/初始化核对；从整机实际实例导出验证 |

独立参考解释算法语义，RTL 测试解释硬件行为，网表测试解释实际综合输入，实板测试解释接口及物理环境。不同层次不能互相替代。共用生成器的参考和实现可能共有错误，要加入独立算例或物理不变量。

优先复用现有自检测试。新增测试针对风险，不照抄实现作为唯一黄金参考。综合优化后比较功能、数值误差、周期/吞吐与资源；不只看资源下降。原设计有缺陷时将修复前后差异列为有意变化，不能宣称严格等价。

来源：[数值与迁移案例](case-numeric-migration.md)。验证通过支持实现合同，不证明应用数据代表性或模型泛化能力。
