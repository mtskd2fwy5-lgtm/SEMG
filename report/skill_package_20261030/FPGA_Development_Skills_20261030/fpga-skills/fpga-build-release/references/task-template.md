# 可直接使用的构建与优化任务模板

## 输入

```text
工程根目录：
目标厂商/器件、工具版本：
顶层、源清单与构建入口：
时钟/复位、约束与 IP/ROM 初始化：
参考实现/现有测试入口：
基线版本或产物：
本次修改/优化目标：
必须保持的数值、接口、吞吐与延迟：
允许改变的精度/延迟（若有）：
用户要求的执行范围：
```

## 提示词

> 使用 `$fpga-build-release` 处理以上工程。先读实际源码、参数/IP、约束及已有报告，指出缺失且影响执行的信息。围绕本次目标定位瓶颈，优先复用已有测试与构建，做出可审阅的变更并执行对应验证。优化比较保持器件、工具、约束、阶段和负载一致；功能变化另列。交付改动原因、测试结果、资源/性能表和产物清单，区分 RTL、网表、静态时序和实板证据。只执行已授权步骤。

## 验收输出

| 项 | 必需内容 |
|---|---|
| 基线与变更 | 输入标识、实际参与构建的源/IP/ROM/约束、允许差异 |
| 行为 | 按风险选择的正常、边界、复位/背压测试；有意变化单列 |
| 资源 | 同阶段 LUT/寄存器、存储、DSP 及布局相关指标 |
| 性能 | 时钟、WNS/WHS、吞吐和起止点明确的时延；不能互相替代 |
| 交付 | 生成物哈希、匹配关系、复现命令、未覆盖范围 |

无需下载实板的报告分析不启动下载；无处理器工程不强加软件/BOOT 检查。未知工具命令先查本地帮助，不虚构参数。
