# 案例：部署合同与泛化是两种验证

性质：模型回放与记录分析摘要，供含数据驱动推理模块的 FPGA 工程参考，不是流式技能的必需前提。

**观察**：同一冻结 INT8 模型与判决策略，在不同采集条件记录上的总体成绩由约 98.35% 降到约 84.82%；部分错类仍给出约 99 的高分。低分拒识和高分错类不能通过同一种阈值调整解决。

**处理方法**：核对真实 RTL 特征缩放、窗口和导数归属，复用生产 C 推理/判决进行回放；按完整批次分开模型探索与冻结验证。混合标签切换点未知时整段排除单类评分，不猜时间点。来源：`report/emg002_20261030/old_model_metrics.json`、`report/emg002_20261030/label_correction.json`。

**配置恢复**：模型文件同时约束编码/特征合同、长度/CRC、范围；校验完再事务替换。历史验证成绩不能当当前新数据验证。来源：`report/hdc_model_sd_20261029/README.md`。

**复用边界**：案例准确率只属于指定数据/口径，不是本技能带来的模型收益。工程主张应分“实现等价”和“应用有效”，也不把窗口数当独立重复次数。
