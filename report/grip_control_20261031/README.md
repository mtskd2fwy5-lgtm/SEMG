# 肌肉协同连续抓握

## 分工与映射

沿用已发布 PL 硬件。NMF C1/C2/C3 仍在 PL 求解；PS 复用协同反馈的 C2 平滑值（25 ms 步长、EMA 1/8），与同序号的 PL 动作结果连接。稳定类别和当前原始类别都为握拳时，C2 控制放松与握拳两套已确认映射之间的插值。其他动作与静息门控输出放松映射。

舒适抓握参考使用 0.5 秒稳定期加 3 秒连续采样。正式采集期间必须有有效、未门控的握拳；断流、离页或识别不符会中止。参考为本次佩戴的相对活动值，不持久化，也不是测力或 MVC。

相对参考值的 0–10% 为零目标，10–100% 线性映射为 0–100% 抓握目标，超参考时截到 100%。插值按保存的端点方向计算，兼容拇指与其他手指相反的脉宽方向，不假定所有关节同向。掌部保持 MPU 映射。

PS 每 50 ms 至多提交一组最新五指目标，复用现有 op12 暂存和 op13 原子提交，op11 value=1 启用 PL 直接目标模式。PS `hand_run=4` 标记协同来源，PL 仍为已有 mode3；它不依赖 HDC 学习，不改变 HDC 或 MLP 的原映射。PL 继续执行 50 Hz PWM、每帧最多 20 us 变化、脉宽限位、输出反相及看门狗。

## 操作

1. 完成静息与 MPU 校准，六轴标定及放松、握拳映射。
2. 进入机械手，在逐轴标定或动作映射页点击“协同抓握”。
3. 点击“采集舒适抓握”，保持舒适握拳约 3.5 秒。
4. 放松后点击“启用协同抓握”，再握拳并调整用力；页面显示当前抓握目标百分比。
5. 点击“停止抓握”或“停止输出”，或离开机械手页面，停止 PWM。

停止 PWM 不等于机械手已物理卸力。此功能调节关节位置，未采集机械手接触力，不能宣称恒力闭环、过载检测或已到位。

## 验证

- `run_hand_grip_test.ps1`：生产固件插值方向、幅度、零区、同窗口连接、门控松开、超时、重复、序号和时间回绕、映射/参考/MPU 门槛、两种 LCD 尺寸渲染与离页停止。
- 原机械手固件回归：启动复位、ACK、HDC、滑块与标定。
- 原 LCD 全回归、字体检查与 ARM 生产编译。
- `verify_grip_release.py`：与 V21 的位流、XSA、RTL、约束、模型和 FSBL 哈希对照，绑定本轮测试输入。
- `build_pl_control_boot.ps1`：硬件接受门、XSA 接口、应用及 FSBL 加载段和 BOOT 位流分区一致性验证。
