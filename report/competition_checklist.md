# AMD FPGA 自主选题赛道提交核对

本清单依据 2026 年 AMD FPGA 赛道选题指南 3.3 节，对当前整合包的提交材料进行核对。组别资格、提交时间及现场安排以赛事通知为准。

| 指南要求 | 提交材料 | 核对结果 |
| --- | --- | --- |
| 工程源码与实现说明 | `src/`、`sw/`、`board/`、`build/` | 包含 PL RTL、PS 裸机程序、板级约束、Vivado 块设计输入和可复现构建脚本；README 说明从工程重建到 BOOT 打包的步骤。 |
| 仿真、参考对比与实现证据 | `sim/`、`tools/`、`report/submission_evidence/` | 包含 HDL/固件回归、模型及数据工具、资源和时序报告、CDC/DRC/方法学检查记录；历史证据与当前源码快照的差异在清单中注明。 |
| 技能包 | `skill/` | 提供 FPGA 构建发布、流式验证、PS/PL 联调和设计报告技能，含使用范围、案例、脚本、验证及失效条件。 |
| 设计报告 | `report/design_report/design_report.docx` | 说明作品背景、系统框图、软硬件分工、设计实现、验证结果和应用场景。 |
| 大模型协作材料 | `report/ai_collaboration_20261103/` | 提供协作记录索引及整理说明；不将摘要标作逐字记录。 |
| README 与目录结构 | `README.md`、`MANIFEST.md` | README 包含项目简介、目录说明、环境要求和复现步骤；清单记录文件来源与 SHA-256。 |
| 开源与第三方许可 | `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md` | 原创内容采用 Apache-2.0；第三方软件、IP 与字体按其原许可使用。 |

## 验证边界

在无厂商工具环境下运行 `python skill/validate_package.py` 与 `python skill/test_portable_tools.py`，检查目录、链接、文件清单和便携工具行为。干净快照尚未由本次检查重新执行完整 Vivado/Vitis 综合实现，也未替代目标板上的采集、显示、SD 写入和机械手实物验证；对应历史报告仅证明其记录所绑定的工程状态。

## 赛道关注点

报告和现场演示应围绕 FPGA 逻辑结构、接口协议、时序与资源、功能验证和可复现流程展开。协作记录与技能包应呈现可检查的输入、输出、修正过程、验证方法和适用边界。自主选题的评分权重和提交细则以选题指南及赛事通知为准。
