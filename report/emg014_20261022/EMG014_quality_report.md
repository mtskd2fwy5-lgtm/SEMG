# EMG014：调整 CH6 接触后的评估

用户确认：本次与 EMG013 条件相同，只调整 CH6 接触/松紧。

共 660,028 帧，165.007 秒，4000 Hz；序号连续，无丢帧、倒退或重复。raw 满量程样本 0。

raw 自动质量状态 CHECK；processed PASS。raw 无满量程削顶。全记录处理后 PC1 为 70.5%，初始静息段为 97.8%；排除 CH4 后分别降至 32.4% 和 28.3%。这表明 PC1 提示主要由 CH4 的尖峰波动主导。处理后全程 50 Hz 窄带功率占 20–450 Hz 功率约 0.12–0.19%/通道。
