# LCD 康复训练任务实现

版本：`20261023_REHAB_V1`。日期：2026-10-23（Asia/Hong_Kong）。

## 使用方法

1. 进入监测模式，停止现有 SD 波形记录。
2. 点击 LCD **菜单 → 康复训练**，也可从设置页面底部进入。
3. 选择单动作或四动作组合。单动作支持张开、握拳、腕屈、腕伸；组合按此顺序循环。
4. 设置重复次数 3/5/10、保持 1/2/3/5 秒、休息 2/3/5 秒。组合的次数指每个动作次数，总数为四倍，最多 40 次。
5. 点击开始，在提示静息校准时保持放松。已有静息校准函数重新运行，不改变模型特征、权重或判决参数。
6. 跟随放松、动作、保持和休息提示。连续完成休息后才开始下一次，最后一次动作之后也有放松恢复段。
7. 需要时暂停或结束。暂停后继续会重新校准并重新开始当前未完成动作的放松准备，已完成的结果保留。
8. 查看结果页。默认自动写入 SD；关闭自动保存时，可在结果页手动保存。保存失败显示错误码并允许重试。

离开训练页或打开菜单会暂停任务。训练进行中不能修改任务设置。训练期间启动波形记录也会暂停任务，继续训练前应停止波形记录并回到监测模式。记录和训练概要保存使用同一个已有 SD/FatFs 驱动，不引入额外文件系统。

## 完成判定

- 消费真实分类结果帧，复用现有静息门控、Softmax 模型支持分数和稳定姿态策略。
- 当前原始候选和已接受的稳定姿态必须同时等于目标，候选支持分数至少 50，且当前没有被静息门控。
- 当前候选不再支持目标，即使姿态策略仍短暂保留旧姿态，也停止保持计时。
- 只有连续的新推理窗口能增加保持时间；相邻结果序号必须增加 40（现有每 25 ms 的推理步长）。重复结果不能计时，序号缺口会重置连续保持。
- 观察间隔超过 75 ms 会重置连续证据；即使存在调度延迟，每个相邻推理结果最多增加 25 ms，避免延迟被当作额外动作证据。
- 没有新结果超过 250 ms 时暂停，静态画面不能完成动作。
- 放松同样要求稳定静息且有静息门控或有效的静息候选支持；需要连续满足设置的休息时间。
- 单次动作从提示开始最多等待“保持要求 + 10 秒”，超时记为失败一次，再进入恢复段；连续无法放松 15 秒、校准等待 10 秒时暂停。
- 姿态预览按钮、MPU 方向和页面刷新不会产生训练完成事件。

阈值 50 是沿用稳定策略的支持门槛口径，不是 50% 实际正确率。当前任务完成判定依赖现有五类识别器，未测量手指真实角度、力量、关节活动范围或临床功能量表。

## 结果与 SD 文件

LCD 显示成功次数、超时次数、计划完成率、已评估次数、成功动作平均识别响应、保持中断次数和各动作成功/评估数量。

- 计划完成率 = 成功次数 / 原计划动作总数；提前结束时未执行的计划不会被算成成功。
- 平均识别响应只统计成功试次，是屏幕提示到首次同时满足候选/稳定姿态/支持条件的时间。包含识别窗口和稳定策略的影响，不是肌电起始或运动反应时间的直接测量，也不是显示器端到端实测延迟。
- 超时记入已评估试次；暂停或提前结束时未完成的当前试次不计入已评估次数。提前结束另有 aborted 标记。
- 保持中断计数记录已进入保持后的不匹配/连续性中断；暂停后当前试次重新开始，不把两段时间拼接。

文件名使用 FAT 8.3 兼容的 `RH000.CSV` 至 `RH999.CSV`，通过 CREATE_NEW 避免覆盖既有文件。与 `EMGxxx.BIN` 分开命名。

CSV 固定 11 列：

`kind,index,target,success,response_ms,hold_ms,breaks,duration_ms,reserved,key,value`

- `meta` 行包含固件和模型标识、任务设置、总数/成功/超时、提前结束、有效训练时间、支持阈值及保存时最近一次每路静息校准 MAV。
- `trial` 行记录每次已完成或已超时的目标、结果、首次响应时间、连续保持时间、保持中断和该次提示后的经过时间。
- target：1 张开、2 握拳、3 腕屈、4 腕伸。
- 自动/手动保存只保存结果，不自动录制原始波形。任务提示不当作真实动作标签写入原有波形录制。
- 暂停时间不计入有效训练时间；当前无 RTC，使用本次上电内的相对时间，不伪造绝对日期。
- 保存成功是写入、同步、关闭均返回成功；短写、同步、关闭、打开失败均会返回错误。失败留下的部分文件不会在重试时覆盖，可能需要之后清理。

## 实现位置

- `sw/ps_uart_print/rehab_training.h`：独立、可测试的任务状态机。
- `sw/ps_uart_print/lcd_rehab.h`：LCD 页面、毫秒累计、结果统计及有界 CSV 构造。
- `sw/ps_uart_print/main.c`：菜单/设置路由、真实结果帧观察、非阻塞服务与动作分发。
- `sw/ps_uart_print/sd_record.c` / `.h`：复用现有 SD 驱动保存训练摘要；不更改 BIN 格式。
- `tools/gen_hz_glyphs.py`：将训练页面文字纳入原生灰度字体生成，避免新中文缺字。

PL 位流、模型参数和原有姿态稳定策略保持当前候选版本。本轮是 PS 应用功能扩展，没有重新综合 PL。已有稳定镜像另存为 `build/boot/BOOT_20261022_POSE_STABLE_V2.BIN`，供跨日对照或回退。
