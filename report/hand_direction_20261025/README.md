# 机械手实测脉宽方向

版本：`20261025_HAND_CONTROL_HDC_DYNAMIC_V8`，继承 V7 的可追加 HDC 手势及可选映射。

已生成 `build/boot/BOOT_20261025_HAND_CONTROL_HDC_DYNAMIC_V8.BIN`，5,057,812 字节。硬件验收四项通过（沿用 V7 bitstream，WNS +0.441 ns、WHS +0.036 ns），ARM 编译及完整 BOOT 分区配对校验通过。复制到启动卡后命名为 `BOOT.BIN`；本轮未写入启动卡。

## 用户确认的现象

逐轴减小 PWM 脉宽时：

| 轴 | 实际动作 |
|---|---|
| 0，掌部旋转 | 向左转 |
| 1，拇指 | 收拢 |
| 2，食指 | 伸展 |
| 3，中指 | 伸展 |
| 4，无名指 | 伸展 |
| 5，小指 | 伸展 |

这是用户对当前机构的实测方向记录，不是六轴同时执行的动作，也不是新的自定义手势映射。各轴标定页及五指映射页显示当前轴对应提示；掌部仍由 MPU 控制。

拇指和其余四指的开合方向相反，不能把五指统一按“脉宽减小等于张手”处理。握拳、张手及自定义手势仍要逐指记录真实目标脉宽。方向信息不能确定各指伸直、收拢的具体数值，不自动以 500/2500 us 作为行程端点，不修改已记录的限值或映射。

掌部脉宽减小向左与现有 MPU 映射同向：相对角度增大时脉宽增大，保留左 45°、右 225°。本轮不改 PL RTL 或 PWM 协议，使用已通过 V7 全量验收的 bitstream，重新编译 ARM 并打包独立 V8 BOOT。
