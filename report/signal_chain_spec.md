# Signal Chain Specification

## Initial baseline

- Input: signed 24-bit ADS1299 code, one sample per channel at the configured rate.
- Baseline estimator: first-order IIR, `b[n+1] = b[n] + (x[n]-b[n]) / 2^N`.
- Rectification: absolute value after baseline subtraction.
- Window feature: sum of rectified samples over `WINDOW_SAMPLES`.
- Default window: 200 samples, corresponding to 200 ms at 1 kSPS.
- Default hop: one completed window initially; a later version can add a 50-sample hop buffer.

## Clock and CDC constraints

- Board PL clock: 25 MHz, period 40 ns, `PL_CLK = B34_L12P = U18`.
- ADS1299 SCLK: 1.25 MHz, generated by the RTL from PL_CLK, divide factor 20.
- `DRDY` is asynchronous to PL_CLK and passes through a two-stage synchronizer before edge detection.
- Add exact DOUT input-delay constraints after the final SPI capture edge and PCB trace lengths are fixed.

## Why this is the first hardware block

This block is independent of the ADC brand and can be compared against a Python/MATLAB reference using the same signed sample file. It establishes a measurable PL workload before neural-network deployment.

## Required checks

1. A constant input must converge to a small rectified value.
2. Positive and negative pulses must produce the same rectified magnitude.
3. A completed window must assert `feature_valid` for exactly one clock.
4. The accumulator must not overflow for the selected ADC range and window length.
5. RTL output must match the fixed-point reference within the stated rounding tolerance.
