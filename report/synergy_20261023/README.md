# PS 协同活动显示原型

日期：2026-10-23。阶段：软件原型，已有用户测试的定性反馈，尚未完成定量实测验收，不驱动机械手。

## 用户测试观察（2026-10-23）

用户反馈原文：“测试发现肌肉协同确实在一定程度上反应用力程度”。该观察支持继续验证相对肌电活动强度反馈，但尚无本次测试的原始数据、动作/姿势、分级用力标签或外部测力参考，不能据此报告力估计精度、线性度或跨佩戴稳定性。

当前固定 W 的 NMF 从八通道 MAV 幅度估计 C，没有逐窗去除总幅度；同一通道活动模式整体增强时，C 通常也会增大。因此该响应符合实现预期，也可能主要来自输入幅度变化。它本身不能证明协同分解比总 MAV/RMS 更准确地反映用力。页面百分比仍为训练数据参考归一化，不是力量百分比。

后续可在同次佩戴、相同动作及腕部姿势下，重复“放松→轻→中→较强→放松”，比较未截顶 C、总 MAV/RMS 的分级单调性、重复性及近似残差；再独立检查重新佩戴后的变化。有同步测力参考时才进一步验证实际力与指标的关系。康复反馈可先定位为经个人/动作参考校准的相对肌电活动强度，不直接作为舵机输出力量或临床疗效指标。

## 使用

候选镜像为 `build/boot/BOOT_20261023_SYNERGY_V1.BIN`。备份启动卡原镜像后，复制候选并命名为 BOOT.BIN，断电重启。整机正常供电、进入监测模式后，依次点击顶部“数据→频谱→协同”。再点“数据”回到数据页，点“手势”回到主界面。

协同页有三条活动条、相对系数 C 和最近 10 秒趋势。活动条和历史图以 EMG008/009 固定基底下系数的第 99 百分位为显示上限；它不是最大随意收缩 MVC 归一化，也不是力量百分比。超过参考时显示“超参考”，曲线限制在图框内，但 C 的数值保留。C 用均值 ADC counts 标度显示，内部保留 Q8 小数。

“近似偏差”是 `sum(abs(e - W*C)) / sum(e)` 的 L1 相对残差，以百分数显示；它不是分类置信度，也不是临床质量评分。静息小量化值附近的残差只能作参考。高偏差意味着这组三协同基底不能很好地近似当前八通道 MAV。

此页仅在监测模式收到完整特征窗时更新。无新窗超过 500 ms 显示等待状态，保留的历史不冒充新数据。特征序号缺口或超过 500 ms 的停顿会清空历史。实时 UART 波形录制模式不解析特征，所以该模式会显示等待；SD 记录在监测模式下可同时工作。

## 实现

- 沿用 PL `feature_bank` 的 400 点窗口、100 点步进、4 kSPS：每 25 ms 接收完整的 40 项特征后，旁路读取 8 项 MAV sum。
- 基底 W 只在 PC 拟合，来源仅 EMG008/009 的 processed CSV，随机种子 7。拟合沿用 `tools/nmf_validate.py` 的无标签在线字典算法。`tools/export_synergy_model.py` 保存来源 SHA256、参数及导出矩阵到 `model.json`，可重复生成固件头文件。
- 板端固定 W，每窗重新投影初始化 C，再作 8 次乘法更新。Q15 权重、Q8 系数、uint64 中间值；全零和突增后均能恢复，不沿用可能锁零的旧窗初值。
- 近似分解无动作标签、无特定肌肉命名。每列 W 的尺度固定；三个系数不是三个已辨识出的解剖肌群。
- 图历史每 4 个窗口取一点评价，共 100 点；显示采用原有合并刷新和 draw-list 快照、三帧缓冲。没有新 UART/SD 包类型或 RTL 修改。
- MLP logits、类别、置信度、静息门控、康复判定、SD 标签的计算保持原路径。自校准环向映射未加入本旁路；NMF 始终使用物理 CH1–8 的原始顺序。

## 验证与限制

`build/scripts/run_synergy_test.ps1` 编译并运行真实 C 头文件，验证全零恢复、强度阶跃、复位确定性、输入上限，并对 EMG008/009/018 连续回放，与独立双精度固定 W 参考比较。数值结果在 `numeric_validation.json`。此处的系数误差是定点实现精度，不是发力测量准确率。

回放的固定基底 L2 相对重建残差中位数约 32–42%，95 百分位约 55–64%。这是较粗的八通道包络压缩原型，不能替代通道活动分析，不能用此前在线更新 W 的 NMF 误差/分类指标代替本版本结果。EMG018 只用于回放检查，未参与 W 拟合或显示参考标定。

`build/scripts/run_lcd_firmware_test.ps1` 检查真实特征包到系数、完整窗条件、序号回绕/丢窗、三曲线历史、超参考、等待提示、页面路由、MLP logits/类别及标签不被修改，涵盖 800×480 和 1024×600 的真实渲染、帧缓冲保护及 draw-list 一致性。源字体生成后通过字模测试。

ARM 编译、启动包生成和位流分区校验均已通过。候选内两个 PS 加载段的文件字节与本次 ELF 对比一致，产物 SHA256 和检查状态见 `artifacts.json`。编译只有现有 Xilinx xilffs `ff.c` 的 unused `vol` 警告。标准 `build/boot/BOOT.BIN` 未覆盖，未写入 SD 卡。

未修改/重新综合 PL，不声称 PL 资源或性能已验证；PS 执行耗时、LCD 实际刷新率和 DMA 是否丢帧仍需实机检查。

首次上板建议观察：静息 10 秒，张开/握拳/腕屈/腕伸各做三次，每次保持 3 秒再放松 3 秒。查看 C 是否重复响应、等待状态是否异常出现，并在数据页检查特征/原始缺帧计数。重复佩戴后需再次确认基底近似，不能把本版固定参考当成自动跨佩戴校准。

本原型不设置“哪条曲线对应哪块肌肉”的命名，不输出力矩或力单位，不连接 PWM 执行器。
