# LCD 点击反馈与滑块标定 V9

版本：`20261025_HAND_CONTROL_HDC_DYNAMIC_V9`，2026-10-25。

## 界面操作

- 公共按钮点击后填色加深、边框高亮，原有选中状态保持独立。首页卡片、通道评分卡片和 MAV 通道卡片也有边框反馈。
- 跳页导致原按钮消失时，新页在原点击位置短暂显示接触圆环；同页按钮只显示按下高亮。
- 反馈从包含本次点击的帧提交显示后保持约 180 ms，避免较慢重绘把反馈提前耗尽。多次点击只保留最新一次；按住不重复执行普通按钮。
- 点击反馈表示触摸已收到，不代表被前置条件阻止的操作已成功。原有错误、状态和互斥条件继续生效。

## 机械手标定

1. 打开“机械手控制 → 逐轴标定”，选择六路中的一路。
2. 滑块粗调；`-50 / -10 / +10 / +50 us` 按钮微调。调整时通过既有 PL 手动指令同步驱动当前轴，其余五路无 PWM。
3. 滑块可连续拖动，松手、触摸失联、坐标非法、退出页面或点击停止时取消本次驱动；故障同样释放拖动捕获，持续按住不能自行重启。
4. 微调按钮及“驱动当前轴 1 秒”采用原有 1 秒期限，后续操作可续期。切换轴先停旧轴；输出期间可记录脉宽上下限，记录后先停止再上传。
5. “动作映射”页的滑块和微调只编辑待保存值，不自动驱动；点击“记录本轴目标”才修改映射，五指确认与联动逻辑沿用 V7。

滑块的 500–2500 us 是现有协议可编辑范围，不是各轴已经验证的机械安全行程。仍需逐轴实测并记录限位。启动默认停止，普通 PWM 无实际角度/力反馈，首次上电实际姿态未知。

按用户要求移除 V8 标定页方向提示。实测事实仅留文档：脉宽减小时拇指收拢，其余四指伸展，掌部左转。MPU 相对范围仍为左 45°、右 225°；不据此自动生成五指目标。

## 实现与继承

- 改动位于 PS 显示、触摸与手动控制层，复用 PL 既有 opcode 5 同轴更新、ACK、心跳和停止机制。
- 未收到 ACK 的命令保持不变，拖动仅合并保留最新目标，不向队列追加全部中间点。
- 复用现有已验证 PL bitstream/XSA，不重新综合逻辑，不覆盖历史 V8 镜像。继续继承信号链、康复、HDC、MPU 和 SD 功能。
- HDC 可追加学习库及自定义映射仍在 RAM，重启不保留；LCD 中文拼音命名仍未实现。
