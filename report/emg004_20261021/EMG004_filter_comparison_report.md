# EMG004：50 Hz、梳状与选择性陷波离线比较

日期：2026-10-21。数据来自本目录已解码的 `EMG004_raw.csv` 与 `EMG004_notch50.csv`，共 89.62675 秒；CH1–6 在手腕，CH7–8 近肘部，均为肌电通道。

## 结论与采用建议

补测增加了用户提出的**现有较宽 50 Hz 陷波 + 窄带梳状滤波串联**。这一组合可兼顾基频与倍频，不能沿用前一轮仅比较直接替换方案的结论来否定梳状滤波。若目标是同时抑制多次谐波，现有 notch50 + 1 Hz 梳状是值得进入板端验证的候选；若优先减少频谱改动，则保留按需追加 250 Hz 的候选。还没有独立验证数据支持最终优劣或分类精度结论。

| 串联候选 | 50 Hz 邻域占比 | 倍频邻域占比 | 相对现有 notch50 的 50 Hz 额外衰减 | 倍频额外衰减 |
|---|---:|---:|---:|---:|
| notch50 + 1 Hz 梳状 | 0.037%–0.088% | 0.30%–1.11% | 1.65–2.39 dB | 3.59–9.15 dB |
| notch50 + 2 Hz 梳状 | 0.022%–0.051% | 0.13%–0.53% | 4.10–4.88 dB | 6.53–12.76 dB |

串联 1/2 Hz 梳状相对基准在倍频 ±3 Hz 之外的实测功率分别减少约 0.08%–0.28% / 0.32%–1.07%；同一排除口径下 CH1–7 动作/放松 RMS 比值最大变化约 0.081% / 0.224%。平坦谱模型的带内功率减少分别为 4.51% / 7.13%（基准 1.81%），不是有效肌电损失的实测值。CH8 突发仍存在。

原比较中，单独 1/2 Hz 梳状在谐波上的抑制更强，但 50 Hz 邻域残留高于现有 5 Hz 带宽陷波；该观察仍成立，适用范围仅为直接替换方案。串联则保留原有 50 Hz 抑制，并在倍频处叠加窄陷波。新增串联实现对记录 notch50 输出再滤波；连续因果处理及所有分析条件与原比较一致。

这是离线方案筛选，**没有修改 RTL、固件、BOOT 或训练模型**。250 Hz 是在这份数据上看到明显窄峰后选择的参数，尚无独立数据验证，不能宣称最优或提高分类准确率。若要工程落地，还需定点参考、RTL 验证及新数据评估。

## 比较条件

| 支路 | 输入与滤波 |
|---|---|
| raw，诊断参照 | 记录 raw，不加工频滤波 |
| 现有 notch50 | 记录中实际保存的 PL 定点 50 Hz/Q10 输出，约 5 Hz 带宽 |
| comb_1Hz | 从 raw 开始，50 Hz 间隔的 IIR 梳状滤波；每个陷波约 1 Hz 带宽 |
| comb_2Hz | 从 raw 开始，陷波约 2 Hz 带宽，作为参数敏感性比较 |
| notch50_plus_comb1/2 | 在记录 notch50 上再串联 1/2 Hz 带宽梳状，不是从 raw 替换 |
| notch50_plus250 | 在记录 notch50 上追加 250 Hz、1 Hz 带宽 IIR 陷波 |

梳状使用 SciPy `iircomb(50, Q, fs=4000, pass_zero=False)`，Q 分别为 50/25，延时长度 80 个采样；除 50 Hz 倍频外也在 DC 有零点，不能将它当作完整的 20 Hz 高通。

所有支路连续处理，不在动作切换时重置状态；新增滤波器采用首样本稳态初值。为便于比较，每路之后统一串接 **因果浮点二阶 Butterworth 20 Hz 高通 + 四阶 Butterworth 450 Hz 低通**。这和前次质量报告使用的零相位带通不同，也和当前 PL 的 HP20/LP215 定点链不同。因此本报告数值应在本表各方案间比较，不能直接与前次带通 RMS 数值混用。

每个 LCD 标注段首尾各剔除 1 秒；Welch 8192 点、50% 重叠、线性去趋势；各段按稳定区间时长加权。50 Hz 邻域为 49–51 Hz；谐波邻域为 100–450 Hz 每 50 Hz 各 ±1 Hz，且限制在 20–450 Hz 内。百分比分母为每个方案自身的 20–450 Hz 总功率。

## 工频与倍频邻域

以下为八通道中最小至最大值，不是通道平均值。

| 方案 | 50 Hz 邻域占比 | 100–450 Hz 倍频邻域总占比 | 倍频邻域功率相对现有 notch50 降低 |
|---|---:|---:|---:|
| 现有 notch50 | 0.055%–0.130% | 1.77%–5.73% | 基准 |
| 1 Hz 梳状 | 0.538%–1.336% | 0.29%–1.03% | 3.58–9.14 dB |
| 2 Hz 梳状 | 0.239%–0.584% | 0.13%–0.50% | 6.52–12.75 dB |
| 现有 notch50 + 250 Hz | 0.055%–0.133% | 1.25%–3.49% | 0.36–2.90 dB |

梳状降低倍频邻域的效果更明显，但当前 50 Hz 陷波更宽，对偏离中心频率的成分抑制更强。窄梳状并不保证比现有陷波更好地去掉整个 49–51 Hz 邻域；邻域指标也包含真实肌电，不能当成纯干扰的残余功率或真实 SNR。

选择性 250 Hz 陷波保留了现有 50 Hz 抑制；50 Hz 百分比略升主要来自分母变化，不能据此认为它增加了 50 Hz 干扰。CH3/4/6 的倍频邻域总功率分别再降低约 1.79/2.26/2.25 dB；它不会同时去除 150/350/450 Hz 的窄峰。

## 频谱改变与动作特征

将输入假设为 20–450 Hz 平坦功率谱，只考虑工频滤波器自身，积分计算的理论带内功率减少为：

| 方案 | 平坦谱模型下带内功率减少 |
|---|---:|
| 现有 50 Hz 浮点等效设计 | 1.81% |
| 1 Hz 梳状 | 3.01% |
| 2 Hz 梳状 | 5.85% |
| 50 Hz + 250 Hz | 2.17% |

这是理论频率响应的代价估算，**不是实测有效肌电损失率**。记录中没有无干扰的真值，无法区分被滤除部分究竟多少是噪声、多少是有效肌电。

本次实际数据在排除各倍频 ±3 Hz 邻域后，相对现有 notch50 的功率变化为：1 Hz 梳状约 +1.96% 至 +3.94%，2 Hz 梳状约 +1.67% 至 +3.10%，追加 250 Hz 约 -0.01% 至 0%。梳状支路这里功率较高，主要因为其 50 Hz 附近过渡带较窄；**不是恢复了肌电或提高 SNR 的证据**。

按相同的倍频 ±3 Hz 排除口径，对各动作与紧邻前一段放松计算 RMS 比：两种梳状在 CH1–7 的比值相对基准最大变化约 1.62%，追加 250 Hz 最大变化约 0.01%。张手时 CH3/5、握拳时 CH1/4/7 的主要模式仍保留。该指标刻意不计陷波邻域，不代表所有特征均不受影响，也不能替代按完整回合划分的分类验证。

全程加权频谱的中值频率相对现有 notch50：梳状在 CH1–7 下移约 3.9–7.3 Hz，追加 250 Hz 变化约 0 至 -1.5 Hz。它反映滤波改变了频谱，不能定性为生理疲劳变化。因此 LCD 频谱、中值频率与疲劳分析必须明确数据支路，不能混用不同滤波配置的基准。

## 暂态、频率偏移与 CH8

通过理想脉冲计算，排除首个直接输出后，后续响应尾部累计能量达到 99.9% 的时间约为：现有 50 Hz 等效设计 221 ms、1 Hz 梳状 1100 ms、2 Hz 梳状 560 ms、50+250 Hz 816 ms。**这是特定脉冲响应尾部能量指标，不是系统固定延迟或动作识别延迟。** 窄陷波会产生更长尾部，动作边缘仍需处理。

固定梳状对频率偏移敏感。例如实际基频若为 50.1 Hz，第五次谐波在 250.5 Hz；1 Hz 梳状对此只有约 3 dB 衰减，2 Hz 梳状约 7 dB。基频为 50.2 Hz 时第五次谐波落到 251 Hz，1 Hz 梳状对此只有约 1 dB 衰减。这是合成频率响应示例，不是对本次电网实际频率的估计。

CH8 握拳尖峰在各候选中仍存在。在统一因果带通下，约 10% 最强的 100 ms 窗口贡献的功率比例：现有 notch50 为约 64%/91%，1 Hz 梳状约 64%/92%，2 Hz 梳状约 64%/92%，追加 250 Hz 约 64%/92%。滤波没有解决该路短时突发，接触与线缆固定问题仍需排查。
