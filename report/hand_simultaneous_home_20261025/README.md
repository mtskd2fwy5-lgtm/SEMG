# 六轴同时复位与持续保持 V11

版本：`20261025_HAND_CONTROL_HDC_DYNAMIC_V11`。2026-10-25 开始，2026-10-26 完成编译验收；版本名保留开始日期。

## 用户现象与已确认的代码行为

用户反馈每次复位动作不同，尤其无名指和小指复位后又移动。
V10 的流程确实是逐轴发出单轴指令，每轴约 1 秒后关闭 PWM，再处理下一轴，最后也关闭全部 PWM。
因此先完成的轴没有持续的目标信号；实际偏移还可能受初始位置、传动和供电影响，尚无实测角度/电流数据，不能把全部物理现象归因于同一个因素。

## V11 的复位契约

1. 继续读取 SD 双文件中 CRC 正确、代数最新的标定与放松映射。六路标定必须完整，所有目标必须落在已标定范围内；不满足时整次跳过。
2. 五指使用保存的放松目标。掌部相对 0° 仍按已确认的 500–2500 us 对应 0–270°、零位绝对 45°计算，为 **833 us**，不改为中位 1500 us。
3. PS 先上传标定，再通过 opcode 14 暂存六个目标。暂存期间没有任何 PWM。opcode 15 一次提交完整六轴，六路在同一 20 ms PWM 帧起点开始输出。
4. 复位启动约 1 秒后，LCD 显示“复位目标保持中”。这只是命令/输出状态，不代表检测到物理到位。之后保持六轴原目标，不逐轴关断、不自动进入识别联动，不用分类或 MPU 新数据覆盖目标。
5. PS 每约 80 ms 续租，PL 与 PWM 保留原有 250 ms 看门狗。停止、急停、失联、错误或失去组保持状态都会终止输出；不自动重启旧目标。
6. 普通滑块/微调标定继续隔离单轴。组保持时拒绝普通单轴指令直接改写它；先停止再进行标定或联动。现有离页停止策略保留。

整机 PS 应用启动触发一次。只切换舵机电源而不重启整机，不会被当作新的上电复位。首次物理位置未知，不能保证六轴同时到位或每次走相同轨迹；没有增加位置/力反馈。

## PL 协议及资源复用

- 使用原有 96 位 staging 缓冲区，保留行号 3 为复位暂存标记；原普通姿态禁止行号 3，因此两类半包不能相互提交。
- opcode 14：`axis=0..5`，`value=目标us`，只能在停止状态、无故障且该轴已标定时接受。
- opcode 15：校验六个暂存值及全部标定后，一次写入 test_target 并开启六轴组保持。完整提交后清空暂存掩码。
- status[1] 是同时复位能力位，status[0] 是当前六轴组保持位。旧 PL 缺少能力位时，新 PS 拒绝发送复位指令，显示中断，不退回逐轴复位。
- STOP、急停、控制器复位、标定变动都会清空复位暂存有效性。普通自动模式的 EMG/HDC/MPU 新鲜度保护保持原样；不构造伪造的传感器数据绕过保护。
