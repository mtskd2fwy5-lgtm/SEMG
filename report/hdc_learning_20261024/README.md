# HDC 板上自学习验证版 — 20261024_HDC_LEARN_V1

已实现 PS 端引导式 HDC 学习，读取现有 PL 的最终滤波信号特征。支持原五类动作，以及最多三个由用户约定的自定义手势。用户主动指定采样类别，不用 MLP 的预测作为训练标签。

## 安装与操作

1. 将 `build/boot/BOOT_20261024_HDC_LEARN_V1.BIN` 备份复制为启动 SD 卡根目录的 `BOOT.BIN`，保留原 BOOT 以便恢复。工程没有自动写入 SD 卡。
2. 上电保持放松，等待原静息校准完成；停止波形录制和康复任务，进入监测模式。
3. LCD 的“设置 → HDC 自学习”（也可在监测串口发送小写 `h`）。先在“自定义数”选择 0–3，默认 1。开始后、第一条采样提交前仍可改数量。
4. 点“开始 / 清空重学”。首版必须同时学习放松、张手、握拳、屈腕、伸腕和所选自定义类别。自定义1/2/3 的实际动作由你约定，记录下来；例如先只选一种与五类明显不同的手势。
5. 先做并保持目标动作，再点对应类别。程序先等待 40 个特征窗（约 1 秒），再收集 40 窗（约 1 秒）。计数增加一次后先放松，再重新做动作、点击。**每个类别学习三次**，尽量覆盖舒适的轻、中用力；不要为了触发旧识别器额外弯腕。
6. 全部类别学习完成后分步建立原型，进入“独立验证”。**重新做动作，每类验证两次**；类别仍由你按真实动作点击。不要按屏幕预测去选择标签。验证和自由识别都不会更新模型。
7. 完成后页面显示各类 HDC 正确率、HDC 全类、质心全类，以及同一批原五类窗口上的 HDC/MLP 对照。实时区上行为 HDC、下行为缩放质心。这里的“分数间隔”是两个类别原型得分差的归一化值，**不是置信概率**。
8. 点“保存验证结果”，生成 SD 根目录 `HD000.CSV`、`HD001.CSV` 等，不覆盖已有报告。保存的是验证混淆矩阵、参数和诊断，**不是模型文件**。保存错误会显示错误码，可以重试。
9. 可保持供电重新佩戴，点“重测冻结模型”，重新验证全部类别。它清空验证计数、保留原型和量化范围；先保存上一轮结果。点“开始 / 清空重学”才会清除已学模型。

## 范围和判读

- 学习模型只在 RAM 保存，重启需重学。HDC 是本版的独立验证支路，原 PL 识别、康复判定、机械手输出及 SD 人工动作标签保持原流程。
- 有标注的校准后才能认识新手势；没有自动发现并命名未知动作。实时分类总会在已学类别中选择一类，当前未实现未知手势拒识或稳定输出策略。
- 自定义手势目前只学习八路 MAV 空间分布，不含动作时间序列。肌肉分布相近、只有手指微小差异的动作未必可分。先验证一种，再增加类别。
- 每个窗为 100 ms、每 25 ms 滑动；每次的 40 个窗存在重叠，不能当作 40 次独立动作试验。必须放松后重新做学习/验证动作。跨佩戴和轻用力的结果比单次保持时的高分更有价值。
- MLP 对照是固定通道映射下的 INT8 C 镜像原始分类结果，限原五类；不包含 PL 的门控、滞回等策略。自定义类别不计入 MLP 准确率，避免错误比较。
- 离页、打开菜单、切换模式、校准未就绪、PL 未就绪、启动录制/康复、数据超时 250 ms 或特征序号不连续，均丢弃当前未完成的一次采样。已提交的完整采样保留，重新点击类别继续。
- 单窗耗时和丢窗需在实板观察；已通过主机测试和 ARM 编译，**尚未实际启动硬件验证自定义手势**。预览图为八类人工合成数据的界面回归，不代表人体识别准确率。

## 实现和验证

`sw/ps_uart_print/hdc_learning.h` 是不依赖 MMIO 的实际学习器；`lcd_hdc.h` 接入原 LCD、采样与 CSV 保存流程。D=2048，16 级相邻相关的值向量，固定种子7；训练量化范围只由训练数据确定，原型为 int16 累加；所有类别使用相同训练窗数。建立原型每次服务只处理一个训练窗，避免长时间占住主循环。

- `D:\PYTHON\python.exe sim/test_hdc_learning.py --captures`：实际 C 编码、全部原型、预测、得分间隔和质心逐一对照独立 NumPy 实现；测试部分采样回滚、序号/时间回绕、量化溢出、饱和、冻结后重测。
- `build/scripts/run_lcd_firmware_test.ps1`：实际固件特征解析 → LCD 点击 → 八类各三次学习、两次验证 → 保存及错误重试；800×480/1024×600 的帧一致性、显示边界、旧功能回归。
- `sim/pl_control_firmware_test.c`：控制邮箱与 PL 决策权保持、HDC 自定义类别学习、PL 未就绪时取消采样。
- `build/scripts/run_sd_record_test.ps1`、`run_uart_record_test.ps1`：原波形保存、两个报告命名前缀、禁止覆盖和写错误处理、串口格式回归。
- `sim/test_lcd_font.py` 与 `tools/gen_hdc_memory.py --check`：字形基线和固定编码内存一致性。
- `build/boot/build_pl_control_boot.ps1`：ARM 实编译、现有 PL 系数及路由时序检查、XSA 与 bit 匹配、BOOT 全硬件分区和两个应用加载段匹配。证据见 `artifacts.json`。

## 旧五类数据回放（不是自定义手势实测）

同一次录制中，各类首个合格动作段取前 120 个稳定窗训练，全部测试窗来自学习段之后的完整独立动作段。训练和测试不共享动作段，量化与原型不使用测试数据。此回放把首段 120 窗分三组，**不等同于实板要求的三次重新做动作**。准确率按窗口计算；该结果只证明当前算法在已有数据上的表现，不能外推为新手势表现。

| 数据 | 测试窗 | HDC | 缩放质心 |
|---|---:|---:|---:|
| EMG008 | 1919 | 77.49% | 89.53% |
| EMG009 | 6588 | 95.02% | 97.59% |
| EMG012 | 5022 | 67.34% | 79.11% |
| EMG013 | 4675 | 66.46% | 63.47% |
| EMG016 | 1791 | 79.23% | 71.75% |

HDC 尚无稳定优于简单质心的证据，所以两者同时上板比较，不把高维算法本身当作性能保证。完整混淆矩阵和源文件哈希见 `replay.json`。
