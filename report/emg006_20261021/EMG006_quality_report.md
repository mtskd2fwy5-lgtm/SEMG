# EMG006 信号质量分析

分析日期：2026-10-21。源文件：`F:/EMG006.BIN`。

## 结论

本次记录能观察到明确的张手和握拳活动，但不能直接把完整记录作为干净训练集。与 EMG005 的同长度初始放松窗口比较，八路中七路的原始 50 Hz 幅度增加，多数通道的谐波也增加。单次 50 Hz 陷波有效，但没有解决谐波、低频基线运动和 CH5 屈腕段的突发干扰。

用户已确认尚未安装 `20261021_LINE_FILTER_V1` 启动文件，电极仍为 CH1–6 在手腕、CH7–8 在近肘部，八路均采集肌电。因此本记录反映旧固件；不能用它评价新“陷波＋梳状＋带通”链路的效果，也不能用 CH8 判断 BIAS 输出是否稳定。

## 数据与方法

- SEMGSD1 v1，8 通道，每通道 4000 Hz，690150 帧。按保存行数计算时长 172.5375 秒。
- 文件大小 35888312 字节；无不完整尾帧。
- SHA256：`c9d6a1410fa177a88db1787f2fefecc10bb86a9a3205c373e1c29aee77bb34c4`。
- 所有幅度使用 ADC counts；未假设增益、参考电压进行微伏换算。
- 频谱：各标注段首尾各去 1 秒，Welch 8192 点、50% 重叠、线性去趋势，再按稳定段时长加权。
- 50 Hz 邻域为 49–51 Hz；谐波邻域为 100、150、200、250、300、350、400、450 Hz 各 ±1 Hz，与 20–450 Hz 分析范围取交集。
- 工频及谐波百分比以对应数据支路的 20–450 Hz 功率为分母。谐波邻域还包含真实肌电能量，不能把全部邻域功率都判为干扰。
- 动作比较使用去除上述工频及谐波邻域后的 20–450 Hz RMS，与该动作紧前的放松段比较。这是活动幅度比，不是生理 SNR 或分类准确率。
- CH5 突发性与包络图使用“记录的 notch50，再离线进行零相位四阶 Butterworth 20–450 Hz 带通”。该离线处理不同于当前或新版 PL 的实际输出。

## 记录完整性

在第 339 个零起始行，即保存时间约 0.08475 秒处，序号从 31570 回退至 31059。最初 339 帧的 raw 与 notch50 载荷随后在第 512–850 行完整重复。这属于旧版启动 FIFO 回放问题。

没有检出向前缺帧事件，也没有相邻相同序号；但这不等于没有重复数据块。记录含 10 次正常的 16 位序号回卷。所有用于本报告频谱及动作比较的保留稳定段均已检查序号连续，启动异常被排除在这些窗口之外。

整个记录时间轴是保存行时间，不是独立硬件时钟；启动回退意味着不能把总行数对应时长直接视为严格连续的实际采样时长。格式没有提供 CRC 证明所有载荷无误。F 盘文件时间显示为 2026-01-01，不能据此认定实际采集日期。

## 量程和低频

八路 raw 和 notch50 均未出现数字 ADC 满量程样本。raw 最大绝对值占满量程比例依次为 8.34%、17.36%、5.51%、26.18%、12.35%、2.40%、20.70%、25.40%。因此本文件没有 ADC 数字削顶证据；这不能证明模拟前端或 BIAS 反馈正常。

动作前后可见较大基线改变。raw 稳定段 0.5–20 Hz 功率占 0.5–450 Hz 的比例，CH1–8 分别为 80.87%、42.55%、78.24%、93.70%、99.83%、56.55%、10.24%、53.97%。此指标不包含直流与低于 0.5 Hz 的漂移。CH5 的低频占比尤其突出。

本次同一记录内，50 Hz 邻域功率衰减为 26.10–33.21 dB，说明旧陷波器确实工作。将记录的 notch50 与现有旧版整数参考模型比对，5–10 秒的最大误差为 0–1 count，也支持它仍是旧单陷波出口。

100–450 Hz 谐波邻域的绝对 RMS 在陷波前后几乎不变。50 Hz 被去除后分母变小，因此谐波百分比升高，并不表示滤波器制造了这些谐波。频谱可见 150、250、350 Hz 窄峰，CH4 最突出：其 notch50 的 250 Hz 邻域占 30.74%，350 Hz 占 12.01%，150 Hz 占 5.46%。

CH5 的谐波百分比较低不能解释为质量最好：它的宽带和突发成分会扩大分母。

CH1 的原始 50 Hz RMS 约为上次的 10.5 倍；CH8 略有改善，其余七路原始工频均增加。多数通道的谐波邻域 RMS 也增加。

去除工频邻域后的 notch50 放松 RMS，CH5 从约 10.26 增至 28.26 counts（+8.80 dB），其余通道大体相近或稍降。因此问题并不是所有频带、所有通道一致恶化，而是工频、谐波，以及 CH5 额外成分突出。未做受控硬件对照，不能仅凭本记录归因于凝胶、接触、电源或 BIAS 中的某一项。

## 动作信息与 CH5 异常

张手相对紧前放松段，去除线频邻域后的 RMS：CH3 增至 15.48 倍、CH2 9.03 倍、CH6 9.37 倍。握拳时 CH1 为 8.33 倍、CH4 7.22 倍、CH7 5.94 倍、CH8 10.74 倍。张手与握拳具有不同的多通道活动分布，可作为后续分类实验的候选信号。

伸腕时 CH7 为紧前放松的 4.70 倍。屈腕段需要更谨慎：CH5 虽有约 150.3 counts 的去线频邻域整段 RMS，但其能量高度集中于短暂异常。

对 CH5 屈腕稳定段进行上述离线带通后，约 10% 的高能量 100 毫秒窗口贡献了 93.87% 的功率；100 毫秒 RMS 的中位数仅 19.48 counts，低于前一放松段的 33.06 counts。约 101.12–103.02 秒有一组显著突发，窗口 RMS 峰值约 973 counts。不能把高整段 RMS 当作持续、强烈的屈腕肌电。

该现象与接触或运动伪迹相符，但文件本身不能确定成因。动作切换处也有较大瞬态，尤其约 78 秒的 CH4；训练前应检查并剔除过渡及异常窗口，不能只依赖整段标签或整段 RMS。

## 共享变化与 BIAS 的解释边界

raw 的第一主成分占 47.15%，通道间绝对相关系数中位数为 0.356；notch50 加离线带通后为 33.93% 和 0.207。这些仅描述差分通道的共享成分，不是电极输入共模电压的直接测量。八路均为肌电，无法用本记录确认 BIAS 是否振荡、输出幅度是否正常或输入共模裕量是否足够。

## 训练使用建议

1. 本次可保留为有标签的实验数据；在剔除启动回放、动作过渡及异常窗口后，可用稳定的张手、握拳等区段做初步分类实验。
2. 不建议把完整文件直接加入正式训练集，也不建议把 CH5 整个屈腕段当作稳定动作模板。先检查约 101–103 秒及同段其他高能量窗口；上述时间是定位线索，不是自动认定其余窗口都干净。
3. 训练与部署应使用一致预处理。报告中的离线 20–450 Hz 零相位带通只用于分析，不能当成新版 PL 20/215 Hz 输出或直接混为同一数据域。
4. 下一次采集前，更新已生成并验证的 `20261021_LINE_FILTER_V1` BOOT 并重启，再采集 raw 与最终处理波形对照。更新可以验证记录修复和新处理链路，不能据此保证原始电极信号或接触伪迹自动改善。
5. 增加每种动作的多次重复，并保留放松段；本文件每种动作只有一段，不能据此报告可靠分类准确率或跨次佩戴性能。
