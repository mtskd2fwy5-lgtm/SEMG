# HDC 连续机械手联动

原程序把实时识别资格和机械手联动使能混在一起：识别过渡约 250 ms 没有足够证据便清除判决并 STOP；确认到未映射类别也会 STOP。现在由机械手联动保存最后一个已确认、已标定的五指目标。

- 明确启用后，手势过渡、低间隔、量化超范围或未映射手势保持上次有效五指目标。量化超范围仍禁止接受新目标，界面保留实时等待/超范围提示。
- 新手势通过原稳定投票且存在映射后，将五指暂存并原子提交；掌部继续由 MPU 驱动。
- 单个特征窗口跳号重新收集投票，保留已启用目标；真实数据超过 250 ms 不刷新、模型失效、MPU 失效、通信故障、手动停止、离页等仍停机，不自动重启。
- 模糊判决仍会从主页/虚拟手失效；保持的是机械手的最后目标，不能把保持目标当成当前识别结果。
- 保持期间每 50 ms 刷新五指目标，PL 的 host、MPU、HDC 三个独立租约继续生效；活动目标队列不能饿死心跳和掌部刷新。
- 机械手页面显示“联动中”“等待手势 / 保持姿态”或“手势未映射 / 保持姿态”。停止输出入口保留。

本次仅修改 PS 固件和界面，不改 PL 寄存器协议、PWM 极性、模型格式或 Q32 算法。复用已验收的 V29 位流、XSA、FSBL 和初始化；发布检查按旧产物哈希验证继承，再检查新应用与 BOOT 的实际加载段。

验证包括真实固件 host 运行 3.5 秒命令/ACK与租约、持续歧义、序号跳过、未映射保持、映射后原子切换、断流停机不自启，以及 LCD/IMU、模型存储、SD、串口和 PL 后端失败回归。日志和源码哈希见本目录。

BOOT：`build/boot/BOOT_20261102_HAND_CONTROL_HDC_DYNAMIC_CONTINUOUS_V30.BIN`。构建和打包验证不代表实板机械运动已验证；未代用户写卡。
