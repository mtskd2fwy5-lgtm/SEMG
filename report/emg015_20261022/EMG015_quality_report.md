# EMG015：纯静息信号质量评估

用户标注：与 EMG014 相同条件，本次全程纯静息。

共 225,400 帧、56.350 秒、4000 Hz。全段仅有一个 rest 标注；序号无缺失、倒退或重复。raw 数字满量程样本 0。

自动质量状态：raw CHECK，processed PASS。raw 的 CHECK 来自共享通道成分判据，不是采集帧丢失或数字削顶；processed 无满量程削顶。

| CH3 | 10.0 | 9.9 | 11.4 | 12.3 |
| CH4 | 10.3 | 10.1 | 12.4 | 13.3 |
| CH5 | 10.6 | 10.4 | 12.4 | 13.5 |
| CH6 | 16.4 | 15.8 | 21.0 | 23.3 |
| CH7 | 9.7 | 9.6 | 11.1 | 11.6 |
| CH8 | 11.3 | 11.0 | 13.8 | 15.3 |

CH1–5、CH7–8 的全段 RMS 约 8.4–9.2 counts，CH6 约 15.1 counts；CH6 高于其他通道，但比 EMG014 中 CH4 的突发活动低很多。处理后 PC1 为 27.5%，排除 CH6 后 18.0%。本数据是静息，没有动作诱发肌电，因此主要反映静息噪声和残余运动/接触变化。

## 与 EMG014 放松段对比

| 指标 | EMG014 → EMG015 通道变化范围 |
|---|---:|
| raw 50 Hz RMS | -6.7 至 +1.2 dB |
| raw 100–450 Hz 谐波 RMS | -2.9 至 -0.6 dB |
| raw 去线频 20–450 Hz RMS | -8.8 至 +0.4 dB |
| processed 50 Hz RMS | -12.0 至 -0.1 dB |
| processed 100–450 Hz 谐波 RMS | -3.1 至 -0.1 dB |
| processed 去线频 20–450 Hz RMS | -17.3 至 -0.6 dB |

EMG015 处理后 50 Hz 功率占比为 0.07–0.12%；raw 中 50 Hz 是主要窄带成分。100–450 Hz 谐波指标包含相同频带的背景噪声，不能全部解释成市电谐波。全记录 PC1/自动 PASS 只描述本记录和规则，不直接等于模拟共模电压或 BIAS 性能。
