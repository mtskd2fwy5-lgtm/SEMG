8 通道贴装卡（按难度与动作角色）

CH1指浅屈肌FDS 握拳主通道难度 中
定位
环1→环2 掌侧正中偏尺扇区纵向差分（≈5 cm），避开 FCR/掌长肌腱交界。
对抗验证
保持手腕不动、仅握拳 → 该处隆起；若腕同时屈曲则 FCR/FCU 混入。
落点细化为环上『掌侧正中偏尺』扇区——降低腕屈串扰，握拳信噪比更干净。
CH2指总伸肌EDC 张手主通道难度 易
定位
环1→环2 背侧正中扇区，介于桡侧腕伸群与 ECU 之间。
对抗验证
四指背伸 / 张手 → 中央肌腹收缩。
伸肌群中心位置，信号强；避免贴到桡侧 ECRB / 尺侧 ECU 边缘。
CH3桡侧腕屈肌FCR 屈腕难度 易
定位
环1→环2 掌侧桡侧扇区纵向差分。
对抗验证
腕屈 + 桡偏 → 腕上出现条索肌腱，沿条索向上二指宽贴肌腹。
表层信号好；与 CH1 相邻，注意不要侵占 CH1 的偏尺侧落点。
CH4尺侧腕屈肌FCU 屈腕 · 握持辅助难度 易
定位
环1→环2 掌侧尺侧扇区，沿尺骨面。
对抗验证
腕屈 + 尺偏 → 尺侧隆起。
表层信号好；握拳时 FDS 与 FCU 有协同收缩，作为握拳辅助特征。
CH5桡侧腕伸肌ECRL/ECRB 伸腕难度 易
定位
环1→环2 背侧桡侧扇区（肱桡肌后方）。
对抗验证
腕背伸 + 桡偏 → 桡侧隆起。
与肱桡肌相邻——旋前/旋后时肱桡肌会动，用「背伸 vs 屈肘」区分确认。
CH6尺侧腕伸肌ECU 伸腕 · 尺偏难度 易
定位
环1→环2 背侧尺侧扇区，沿尺骨缘。
对抗验证
腕背伸 + 尺偏 → 尺侧隆起。
表层信号好。
CH7拇长展肌APL 拇指外展（预留）难度 中
定位
环外斜行对：背侧桡侧远端斜行条索（解剖鼻烟窝近端），两片沿斜向肌纤维贴放。
对抗验证
拇指外展对抗 → 斜向隆起出现。
鱼际的拇短展肌是手内在肌，表面电极采不到；APL 为功能最接近的浅层替代。与 ECRB 相邻有串扰。
CH8拇长伸肌 / 示指伸肌EPL / EIP 拇指·示指（预留）难度 难
定位
环外斜行对：背侧远端尺侧、Lister 结节近端；两片沿斜向肌纤维。
对抗验证
拇指单独伸直（其余四指放松）对抗 → 远端尺侧深处收缩。
位置深、信号弱——若采不到有效信号，改贴拇短伸肌 EPB（APL 旁，更浅更易），代价是与 CH7 相邻串扰大；二选一由实测决定。

v3 相对 v2 的调整要点（2026-10-10）

修订逻辑：逐指分化预留 + 左手佩戴

  1. CH1~CH6 重组为双环纵向差分——环1（肘横纹远端约 8cm，肌腹最丰满处）+ 环2（环1 远端约 5cm），每通道 = 环1 一片 + 环2 一片环间纵向差分，环上按 6 扇区分度（掌侧：桡 FCR / 正中偏尺 FDS / 尺 FCU；背侧：桡 ECR / 正中 EDC / 尺 ECU）。逐指分化收益：每指 compartment 在环上投影角度不同，双环 = 6 角度 × 2 纵深空间采样，为后续加单指分类重训预留结构；两条电极带也比 12 片散点好穿戴得多。
  2. 右臂 → 左臂镜像：右手控鼠标、系统佩戴左臂，两视图按左臂镜像重绘（掌视拇指在右、背视拇指在左），上髁标签随侧别互换。
  3. CH7/CH8 不进环：APL/EPL 为远端斜行肌，环带覆盖不到，保持斜行贴法；CH8 维持「难」标注与 EPB 备选。
  4. 环间距 5cm 替代 2~3cm 散点对：拾集体积更大、信号幅度更高，但串扰更宽——换布极后 NN 必须重训（本就是预期流程）。v2 的落点细化、对抗验证、REF 腕横纹位置等经验全部保留。

贴装流程与板上验收

  1. 磨皮 + 酒精清洁全部贴片位点（降低接触阻抗）。
  2. 先贴参考电极（左臂掌侧腕横纹），再贴两条环带：环1 → 环2 按扇区成对贴放（CH1~CH6），最后 CH7/CH8 斜行对。
  3. 每对按卡片「对抗验证」确认肌肉定位，错了重贴。
  4. 全部贴好（含参考）之后再上电复位——严禁带电极悬空上电评估前端性能。
  5. 板上验收判据：8 通道不钉轨；静息 MAV 落到万级内；对应动作通道 MAV 出现 2~5 倍抬升（CH1 握拳 / CH2 张手优先验证）。
  6. 注意：现有 NN 权重训练自 NinaPro DB5（Myo 环带布极），真实布极下分类不准属预期——本轮优先验证信号质量指标，重训属后续阶段。
