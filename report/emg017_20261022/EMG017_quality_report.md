# EMG017：同等条件下信号质量评估

用户说明：与 EMG016 同等条件。按文件标注分开统计放松、张手、握拳、屈腕和伸腕。

共 1,098,578 帧、274.6445 秒、4000 Hz；序号连续，无缺帧、倒退或重复，无 raw/processed 数字满量程削顶。raw 峰值为数字量程的 36.0%。自动状态 raw/processed 均为 PASS；自动 PASS 不能排除短时伪迹或残余工频。
