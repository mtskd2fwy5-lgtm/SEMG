# 疲劳趋势误触发修复（V5）

适用：`20261025_HAND_CONTROL_FATIGUE_V5`，继承当前 PL 控制、机械手、通道质量检查和康复界面。仅重新打包 PS 不会生效，必须更新包含新 PL 的 BOOT。

已生成 `build/boot/BOOT_20261025_HAND_CONTROL_FATIGUE_V5.BIN`（5,051,284 字节）。`package.log` 中四项硬件验收门均通过，BOOT 的完整 bitstream 和两个应用 PT_LOAD 段与构建输入一致。启动卡使用时重命名为 `BOOT.BIN`；本轮没有写入 SD 卡或驱动实板。首次构建的常数扫描阻拦及修正过程保留在 `build.log`，最终验收以 `package.log` 为准。

## 已确认的原因

1. 原模块 `MIN_ENERGY=0`，静息窗也进入 MDF 趋势历史；无效窗不清除已填满的历史。等级判定又没有检查当前活动是否有效。
2. 原等级仅由 16 窗 MDF 斜率决定。MDF 下降后进入平台，斜率回到零，等级会下降；它没有表达同一发力段内已经发生的累计频率下降。
3. 最终带通波形接入疲劳 FFT 后仍右移 8 位。真实处理后波形多为几十至几百个 ADC 计数，量化会吞掉主要信息。原 MDF 又包含了 DC 和带外频率。

## 本次处理

- 复用 `emg_control_policy` 已有的每通道静息 MAV 校准门限，单独导出实际幅度活动状态，与分类置信度分开。原分类、门控及机械手决策格式不变。
- 整个 2048 点窗必须校准完成、数据有效、幅度超过静息门限、识别类别非静息且不变；窗内变化、FFT 输入饱和、故障或未就绪均不评估。活动资格与样本缓冲一起保存，不用处理时刻的状态替代采样时刻状态。
- FFT 输入由右移 8 位改为左移 4 位，保留低幅度信号精度；FFT 输入越界的整个窗口不用于疲劳。原始采集、识别特征及 SD 波形不经过这项缩放。
- MDF 和能量限定在 FFT 的 11–230 bin（21.48–449.22 Hz）；保留原 16 窗斜率 `n2` 作为诊断量。
- 同一连续动作的前 8 个有效窗建立 MDF 平均基线；16 个有效窗后就绪，约 8.2 秒，不含动作边界被丢弃的窗。
- 当前频率用四窗去极值均值，去掉最大和最小 MDF 后平均另两个值；避免单个频率异常被普通滑动平均拉长后满足连续确认。
- 相对基线下降 10%、20%、30% 是本版 1/2/3 级候选，连续 3 窗确认；同一活动段内保持已确认的最高等级，平台期不自动下降。放松、无效窗或动作改变后清除等级及基线。
- LCD 在基线未就绪或失效时显示“待评估”，不把内部 0 级显示成已恢复正常。只改变就绪状态、等级不变时也会触发重绘。

10/20/30% 是工程默认参数，未以临床疲劳标签验证。这里是同一次持续收缩的频谱下降提示，不是力测量、全日累计疲劳、疲劳恢复证明或临床严重度。发力方式、负荷和接触变化仍可能影响 MDF；保持最高等级也不能消除持续伪迹导致的错误升级。无有效 PL 静息校准的 legacy 构建只输出 MDF/频谱，不输出疲劳判断。

## 上板复核

1. 用新 BOOT 启动，按原流程保持放松完成静息校准。静息保持 30 秒，LCD 应为“待评估”，不出现重度等级。
2. 选择一个能稳定识别的动作，舒适持续保持至少 12–20 秒。约 8 秒有效数据后就绪；动作进入频率平台时，已确认等级应保持。
3. 放松，最迟在包含放松的下一疲劳窗输出后转为“待评估”（通常约 0.5 秒，加处理及显示延迟）；重新发力要重建基线。
4. 切换另一动作，确认不会沿用上一动作基线。若持续发力仍频繁“待评估”，同时检查姿态是否跳变、静息幅度门限、电极接触和 FFT 饱和，不以强制维持等级掩盖数据无效。
5. 保留串口 `T s=... lv=... mdf=... n2=... full=... e=...` 和对应动作时间。`full=0` 表示不能评价；`n2=0` 不再要求等级回零。新版 `e` 是新缩放下的带内谱能量，不能直接与旧版数值比较。

尚未完成本版实板试戴和有疲劳真值的实验；原采集数据不能给出临床检测准确率。
