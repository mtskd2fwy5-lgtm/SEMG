8 通道贴装卡（按难度与动作角色）

CH1指浅屈肌FDS 握拳主通道难度 中
定位
肘横纹中点 ↔ 腕横纹中点连线，距肘约 1/3 处，前臂中线略偏尺侧；两片沿肌纤维纵向，间距 2~3 cm。
对抗验证
保持手腕不动、仅握拳 → 该处隆起；若腕同时屈曲则 FCR/FCU 混入。
落点由「近中段」细化为「中线偏尺侧」，避开桡侧腕屈肌与掌长肌腱交界——降低腕屈串扰，握拳信噪比更干净。
CH2指总伸肌EDC 张手主通道难度 易
定位
背侧中线（外上髁 ↔ 腕背中央连线，中下 1/3），介于桡侧腕伸肌群与尺侧腕伸肌之间。
对抗验证
四指背伸 / 张手 → 中央肌腹收缩。
伸肌群中心位置，信号强；避免贴到桡侧 ECRB / 尺侧 ECU 边缘。
CH3桡侧腕屈肌FCR 屈腕难度 易
定位
掌侧桡侧浅层：肘横纹桡侧 1/3 ↔ 腕掌面桡侧连线近中段。
对抗验证
腕屈 + 桡偏 → 腕上出现条索肌腱，沿条索向上二指宽贴肌腹。
表层信号好；与 CH1 相邻，注意不要侵占 CH1 的偏尺侧落点。
CH4尺侧腕屈肌FCU 屈腕 · 握持辅助难度 易
定位
掌侧尺侧缘（小指侧）近中段，沿尺骨面。
对抗验证
腕屈 + 尺偏 → 尺侧隆起。
表层信号好；握拳时 FDS 与 FCU 有协同收缩，作为握拳辅助特征。
CH5桡侧腕伸肌ECRL/ECRB 伸腕难度 易
定位
背侧桡侧（拇指侧）：肱桡肌后方，近中段。
对抗验证
腕背伸 + 桡偏 → 桡侧隆起。
与肱桡肌相邻——旋前/旋后时肱桡肌会动，用「背伸 vs 屈肘」区分确认。
CH6尺侧腕伸肌ECU 伸腕 · 尺偏难度 易
定位
背侧尺骨缘（小指侧）近中段。
对抗验证
腕背伸 + 尺偏 → 尺侧隆起。
表层信号好。
CH7拇长展肌APL 拇指外展（预留）难度 中
定位
背侧桡侧远端斜行条索（解剖鼻烟窝近端），两片沿斜向肌纤维贴放。
对抗验证
拇指外展对抗 → 斜向隆起出现。
鱼际的拇短展肌是手内在肌，表面电极采不到；APL 为功能最接近的浅层替代。与 ECRB 相邻有串扰。
CH8拇长伸肌 / 示指伸肌EPL / EIP 拇指·示指（预留）难度 难
定位
背侧远端尺侧、Lister 结节近端；两片沿斜向肌纤维。
对抗验证
拇指单独伸直（其余四指放松）对抗 → 远端尺侧深处收缩。
位置深、信号弱——若采不到有效信号，改贴拇短伸肌 EPB（APL 旁，更浅更易），代价是与 CH7 相邻串扰大；二选一由实测决定。

v2 相对 v1（2026-09-11 定稿）的调整要点

修订逻辑：手指运动还原优先，贴装难度兜底

  1. CH1 / CH2 是手指还原仅有的两个主通道——五类动作中「握拳 / 张开」完全依赖它们，v2 把两者落点细化到肌腹中心（CH1 中线偏尺侧、CH2 背侧正中），并给出对抗收缩自检，贴歪即知。
  2. CH8 明确标注「难」并给出 EPB 备选：v1 已注明位置深信号弱，v2 把「贴不上 / 采不到」的兜底方案写进图，避免现场卡死。
  3. 参考电极统一到腕横纹：比肘部更易贴、离肌群近、运动伪影更小；放在骨性/肌腱面（无肌电活动）。
  4. 每通道附对抗验证动作：贴完 10 秒即可确认定位正确，不需要等上电看数据。
  5. 腕屈/伸四通道（CH3~CH6）全部为浅层易贴肌肉，难度均为「易」——保持 v1 方案不变。

贴装流程与板上验收

  1. 磨皮 + 酒精清洁全部贴片位点（降低接触阻抗）。
  2. 先贴参考电极（掌侧腕横纹），再按图贴 8 个差分对。
  3. 每对按卡片「对抗验证」确认肌肉定位，错了重贴。
  4. 全部贴好（含参考）之后再上电复位——严禁带电极悬空上电评估前端性能。
  5. 板上验收判据：8 通道不钉轨；静息 MAV 落到万级内；对应动作通道 MAV 出现 2~5 倍抬升（CH1 握拳 / CH2 张手优先验证）。
  6. 注意：现有 NN 权重训练自 NinaPro DB5（Myo 环带布极），真实布极下分类不准属预期——本轮优先验证信号质量指标，重训属后续阶段。
