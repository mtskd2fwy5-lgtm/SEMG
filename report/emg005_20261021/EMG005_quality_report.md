# EMG005.BIN 质量评估及 EMG004 对照

日期：2026-10-21。文件 `F:/EMG005.BIN`。用户确认：CH1–6 在手腕、CH7–8 在近肘部，八路均为肌电；相较 EMG004 只增加凝胶和去角质处理，未更换滤波固件或 BIAS 接法。

## 结论

本次有清晰、重复的张手和握拳特征，可筛选稳定段用于初步训练。最明显的改善是 **CH8 两次握拳均不再被极少数高能量尖峰主导**。但不能说加凝胶后所有通道都降噪：同样的初始放松 1–10 秒窗口中，CH4/5 的原始 50 Hz 明显下降，CH3/8 则上升，多数通道的谐波邻域功率也未改善。基线漂移和动作边缘扰动仍需处理。

没有独立无干扰肌电真值，也没有直接测量接触阻抗，因此无法将变化单独归因于凝胶、去角质或某个硬件原因。动作强度、佩戴压力等也可能影响信号。本次没有修改 RTL、固件或 BOOT，未应用上一轮离线测试的梳状滤波。

## 文件完整性与削顶

- SEMGSD1 v1、8 通道、4,000 Hz；1,081,620 帧，按保存行数折算 **270.405 秒**，完整帧尾，无帧尾截断。
- 约 0.0895 秒后（第 359 个零起始索引处），序号由 30566 回退到 30055；除此之外相邻序号全部正常递增，包括 16 次正常 16 位回绕，没有检测到其他序号异常。
- 前 359 帧的原始及滤波载荷在索引 512–870 处逐字节重复，支持启动缓冲回放/重复的解释。不能将旧解码器报告的 65,024 个缺帧按实际缺失样本理解。异常来源尚未定位。
- CSV 时间戳由行号生成，不能显示上述回退，也不能验证独立采样时钟。所有稳定段评估排除了首尾各 1 秒，首段已避开整个启动异常区间。
- raw 与 notch50 所有通道均无 ADC 正负轨样本。raw 最大绝对码值是 CH4 的 2,393,834 count，占满量程约 **28.54%**，没有 ADC 数字削顶证据。
- 序号与帧长度检查不能排除所有位错误，本格式没有逐帧 CRC。缺少实际增益/参考电压读回，以下统一用 count，不换算微伏；比较两次记录按用户确认的相同配置解释。

## CH8、漂移与动作边缘

CH8 是本次相对上次最明确的改善项。在相同的 notch50 + 离线零相位四阶 Butterworth 20–450 Hz 带通、首尾各剔除 1 秒、100 ms RMS 窗口的口径下：

| CH8 指标 | EMG004 第一次/第二次握拳 | EMG005 第一次/第二次握拳 |
|---|---:|---:|
| 约 10% 最强窗口贡献的带通功率 | 58% / 87% | 26% / 25% |
| 100 ms RMS 中位数 / count | 93.8 / 91.8 | 124.9 / 148.9 |
| 100 ms RMS 的 P95 / count | 724.9 / 621.5 | 198.8 / 237.1 |

005 不再是少量极大尖峰主导握拳能量。因此不能继续照搬 004 的理由永久排除 CH8；可以在后续验证中比较“包含 CH8”与“排除 CH8”的模型表现。但该路工频与倍频邻域仍偏高，不能只依据持续响应增强就当作最优通道。

原始基线仍随动作大幅移动，CH4 尤其明显，约 60 秒、199 秒附近的阶跃在带通后仍形成很大的短时尖峰。它没有 ADC 触轨，但显示量程/自动缩放仍可能被瞬态主导。建议动作特征使用稳定区间，不能把每个切换尖峰都当成肌肉爆发。

稳定区间的 0.5–20 Hz 占 0.5–450 Hz 功率约为 CH1–8：72.2%、62.2%、75.4%、96.5%、96.0%、68.3%、46.6%、53.4%。该比例不包含更慢的直流变化，不能只凭它给所有漂移排序；原始轨迹也需一起查看。多路慢变、阶跃与恢复不能仅靠 50 Hz 或梳状滤波修复。

全程 raw 第一主成分占比 74.8%，通道对绝对相关系数中位数 0.464；notch50 加 20–450 Hz 带通后为 43.1% / 0.167。差分输出有共同成分并不等于直接测得输入共模电压，也不能据此确认 BIAS 回路稳定。

## 训练使用与下一步

1. 放松、张手、握拳可选稳定段开展训练。继续保留 raw，训练与板端推理用一致的处理链，切换尖峰单独标记/剔除。报告中的离线零相位带通不等价于现有 PL 的实时定点带通。
2. CH8 本次可进入包含/排除的对照验证；CH4 要关注动作边缘高瞬态，不能将全程未触轨视为所有窗口都合格。
3. 屈腕仍需补采可重复样本，动作间插入放松以得到局部静息参照；按完整回合划分训练/验证，避免同一次动作邻窗泄漏。
4. 若继续验证梳状或自适应滤波，仍用 raw 离线比较并检验动作特征，不能把降低倍频邻域功率直接等同于分类精度提高。硬件接触固定与滤波都需评估，不能仅靠进一步去角质解决工频。
