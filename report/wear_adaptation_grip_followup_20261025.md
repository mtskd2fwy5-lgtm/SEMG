# 后续验证：佩戴适配升级与抓握比例控制

日期：2026-10-25。

## 用户确认与当前边界

用户要求将前述佩戴适配升级留作后续验证，并询问抓握时肌肉协同能否映射到机械手发力。本记录不代表相关固件功能已经实现，不修改当前 BOOT 或开启机械手输出。

## 佩戴适配升级验证

- 保留当前环向循环偏移、原模型以及独立验证回退。
- 对比原模型、循环偏移、受限幅值/基线适配、环向相邻通道插值及其组合。
- 幅值适配须区分 MAV、WL、能量、ZC、SSC 的变换规律，不对五类特征直接套同一 scale/offset。
- 使用真实跨佩戴批次，按完整动作重复划分适配/验证/测试，避免重叠窗跨集合泄漏；报告逐类结果、静息误触发和切换边界。
- 逐通道数值仿射不等同于论文 SAL 的空间坐标变换与重采样。校准时长、准确率恢复、LUT/DSP 开销均须实测。

## 抓握协同映射的两层目标

现有 C2 为固定 NMF 基底得到的相对活动系数，用户曾观察其随握力增加，但尚无可通用的力标定。当前协同计算/平滑在 PS；PL 机械手只根据已接受的五类动作选择固定六轴 PWM 目标，尚无连续协同输入或力反馈。

1. **比例闭合演示**：静息 C2 和舒适抓握 C2 标定后，将活动归一化为 0–100%，在各指已标定的张开/闭合目标之间插值；加入死区、迟滞、限速、幅度约束和同窗/新鲜度验证。只在明确启用的抓握模式下执行。此输出是闭合目标，不是 N 或真实抓力。
2. **抓力控制**：外接抓力/压力测量，标定后将活动映射为力目标，由实际力反馈控制闭合目标；需验证接触检测、力上限、反馈失效、堵转/过流及停止行为。三线 PWM 本身不提供扭矩/力命令，电流最多是经标定的间接信息。

建议验证顺序：离线 C2 与参考测力的重复性及漂移 → 无接触比例闭合 → 带独立测力的物体抓握。先记录实际力再讨论力闭环指标，不能以更大 PWM 脉宽当作更大抓力。停止 PWM 不保证舵机卸力或机械手松开，失效动作须在机构上验证。

最终实时协同与执行路径按现有总体目标迁入 PL；PS 保留参数配置、LCD 和记录。一个全局 C2 只能提供整体抓握活动目标，不足以推断五指各自的独立力。
