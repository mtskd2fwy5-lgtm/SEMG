# V19 HDC SD 模型库

版本：`20261029_HAND_CONTROL_HDC_DYNAMIC_MODEL_SD_V19`。本版只修改 PS 的存储、模型切换和 LCD 交互，复用 V18 的全部 PL 位流、XSA、FSBL、算法、模型 ROM 和约束。HDC 编码、原型训练及在线推理继续在 PL 执行。

## LCD 操作

1. 在“设置 → 自学习”完成各类别的学习和独立验证，保留原来的验证门槛。
2. 点击右下“模型库”，再点击“另存当前模型”。成功后显示文件名与“断电保留”。
3. 文件保存在启动 SD 卡根目录，自动使用 `HM000000.HDC`、`HM000001.HDC` 等 8.3 文件名。每次另存一个新文件，历史模型不被覆盖。
4. 在列表点击一个文件，再点“加载所选模型”。每页六项，可前后翻页或刷新；界面不设固定的模型槽位数，文件名空间及 SD 容量仍有上限。
5. 加载后可返回学习页重测、自由识别或追加新手势。原有“导出结果”仍保存 `HDxxx.CSV`，它与可恢复的 `.HDC` 模型文件用途不同。
6. 调整虚拟手或机械手映射后，再到模型库另存，以记录这一次调整。模型库不会自动保存，也不会自动加载上次模型。

首次更新固件后需学习并保存一次；旧固件中仅存在 RAM 的模型不因更换 BOOT 自动转存。每次重新佩戴仍按现有流程检查信号并校准，可在加载后“重测模型”检验本次佩戴表现。

## 保存内容与切换行为

快照包含动态类别数、各类 120 个学习窗口的八路特征、2048 维 int16 原型、八路量化尺度、质心累计值、学习/验证计数、完整 HDC/质心混淆矩阵、原五类 MLP 对照结果、验证摘要、自定义五指 PWM 目标与映射标志、22 个虚拟关节角及映射标志，以及机械手标定范围签名。现有固定基础类别及“自定义N”编号沿用原工程；本次不增加名称输入功能。

不保存活动采样、旧实时类别、投票历史、输出使能或正在运行的康复任务。机械手基础动作映射与六轴标定继续保存在原 `HAND0.CFG/HAND1.CFG` 日志中，HDC 快照只携带自定义映射及用于核对的范围签名，不覆盖基础标定。

切换前停止机械手并使旧识别失效。成功后从新数据重新形成稳定类别，需显式启用机械手联动。标定范围不匹配时，清除自定义机械手映射有效标志，保留虚拟手映射，提示重新确认。未通过验证的模型也允许存档，但加载后仍不通过原有跟随门槛；历史验证结果不会被伪造成当前重新验证结果。

波形录制、活动采样、建立原型或正在进行的康复训练期间不执行存取。文件 IO 通过主循环的延后动作处理，分块传输并服务采集；离页会取消尚未执行的模型操作。

## 文件与恢复

`HMD1` 版本 1 使用显式小端字段，不写入指针、结构体填充或内存地址。头部绑定 D2048/Q16、seed7 编码 ROM、八路输入、4 kHz、120/80 学习验证窗口及当前滤波合同。修改编码 ROM 或特征合同须升级合同标识，不能直接复用旧模型。

文件末尾为整个头部及正文的 CRC32 和完成标志。读取时核对版本、维度、长度、类别/内存上限、样本计数、混淆矩阵、原型范围及映射范围；拒绝截断、尾随数据、损坏或不兼容文件。先在原有另一组 32 MiB HDC 存储区恢复，仅在内容、校验、EOF 和文件关闭全部成功后替换活动模型；失败保留当前模型。保存采用 `CREATE_NEW` 并检查 sync/close。若保存中途断电可能留下不完整文件，加载会拒绝，该文件可离线删除，不会覆盖旧模型。

八类别快照约 64.3 KiB。传输使用固定小缓冲，不复制整份文件到栈；现有双 HDC 存储区大小不变，不新增 PL BRAM/DSP/LUT。PS 文件读写用时及真实卡上掉电行为仍需实板验证。

## 测试与发布

- `model_test.log`：12 类完整样本/原型/尺度/质心一致，版本维度与内存边界，头/正文/尾部损坏、截断、多余数据、文件关闭失败回退，失败验证保持失败，恢复后追加。
- `sd_test.log`：真实 SD API 的 4 KiB 分块、短读短写、sync/close/open 错误、非覆盖命名、录制互斥，以及无序目录的排序分页和文件名过滤。
- `lcd_test.log`：800×480 与 1024×600 的真实渲染/触摸，独立模型切换、模拟断电恢复、映射校验、PWM 停止、分页和离页取消，并回归质量页、康复训练、虚拟手与导航。
- `learning_workflow_test.log`：生产 PL 调用分支恢复 DDR 原型后，下个窗口继续调用加速器，不使用软件回退。
- `hand_test.log` / `uart_test.log`：机械手控制、上电复位、保护和串口帧回归。
- `baseline/`：本轮修改前的 V18 源码；`regression_sources.json`：本轮验收输入 SHA256。
- `tools/verify_hdc_model_release.py`：逐项核对 V18 继承与当前测试证据；`artifacts.json`：新 BOOT 的位流、应用和 FSBL 加载段及文件哈希。

```powershell
powershell -ExecutionPolicy Bypass -File build/scripts/run_hdc_model_test.ps1
python tools/verify_hdc_model_release.py
powershell -ExecutionPolicy Bypass -File build/boot/build_pl_control_boot.ps1
```

输出：`build/boot/BOOT_20261029_HAND_CONTROL_HDC_DYNAMIC_MODEL_SD_V19.BIN`。本轮不写启动卡或下载硬件。
