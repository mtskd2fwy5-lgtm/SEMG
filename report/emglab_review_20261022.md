# EMG Lab 网站调研与本项目功能对照

日期：2026-10-22。

## 结论与调研范围

值得借鉴，优先级最高的是把已有的采集和分析能力组织为“佩戴检查 → 校准 → 训练/记录 → 回顾”的完整流程。当前最需要补充的是逐通道质量诊断、可追溯的佩戴校准、单通道疲劳趋势和动作时序统计，而不是重新实现已有波形或 FFT。

证据来自网站当前首页及公开 JavaScript 模块，并与本工程当前源代码核对。首页实际部署为 V2.0，资源版本字符串为 `2.0.0-p7.3.1`，保留 V1.36 入口。搜索引擎和网页文本抓取中仍可能出现旧版信息，因此下述新版功能以实际模块为准。此次是功能与实现调研，计算精度和浏览器全流程交互尚未独立实测。

本报告给出实施建议，没有将建议当作已经完成的固件功能。

## 2. 现有实现与适合移植的改进

### P0：LCD 逐通道信号质量页

现有 PC 报告已经计算 RMS、ADC 轨顶、时序缺口、PSD、部分工频/谐波占比和通道相关性；LCD 有 MAV、波形、频谱及部分状态信息。可以复用计算与数据通路，将其整理为每路可解释的质量面板。

建议 LCD 每路显示：

- 原始输入饱和/轨顶比例、数据中断和重复/异常序号。
- 静息 RMS 或 MAV，以及相对本次佩戴基线的变化。
- 原始信号低频占比、50 Hz 与可分析谐波附近的窄带功率及邻带对比。
- 动作相对静息的幅度增益、疑似接触变化提示。
- 选中通道的原始/最终处理波形和频谱入口。

原始数据用于检查前端饱和、低频伪影和外界干扰；最终处理数据用于评估实际进入识别器的残留。不能用“滤波后 50 Hz 很低”代替“原始信号质量良好”。

仅凭波形不能确诊导线断路或接触阻抗，也不能把多通道相关性/PCA 公共成分直接标为电气共模电压。需使用“疑似接触异常”“共享成分”等准确名称；确定的电极脱落检测需要硬件检测依据。

网站评分的限制：其 A–D 等级采用等权和最差分项封顶，公开实现自身将其标为工程规则；所谓 SNR 还有按幅度分位组估计的口径。可以借鉴展示结构和诊断项目，阈值应由本项目静息、动作、断路、松动和干扰数据验证。我们的“活动/静息比”也应按该名称展示，不能宣称为分离真实肌电与噪声后的 SNR。

固定八通道模型不能因为某路质量差就直接删除输入或随意置零。第一阶段应提示重新调整佩戴、记录异常并保留通道顺序；自动降级识别需要相应训练和验证。

### P0：佩戴校准向导与会话档案

现有 `cal_on_window()` 已有每通道 MAV 静息基线，适合扩展为 LCD 引导流程：

1. 检查接触和信号质量，确认没有明显饱和或数据中断。
2. 采集安静的静息段，显示稳定性并保存每路基线。
3. 采集少量标准动作，检查每路响应及相对历史佩戴的变化。
4. 保存佩戴编号、通道位置、是否使用凝胶、参考幅度、固件/模型版本及处理链标识。
5. 若质量条件不满足，给出具体原因并要求重新完成该段校准。

可参考网站 MVC/参考幅度管理，但显示标准化与模型输入标准化是两项改动。当前模型按既定特征和量化参数运行，若改变其输入归一化，必须同步训练、量化、C/RTL 一致性与跨佩戴验证。轻握拳参考值只能称为“参考收缩”，不应自动标成 MVC。

幅度标准化可以作为降低幅度差异影响的候选方法，不能假定能补偿电极旋转、通道空间模式变化或佩戴松动。CEDE 幅度标准化共识也是按任务选择参考方法，并非一种通用归一化消除全部差异（S11）。

### P1：疲劳页由等级扩展到可解释的趋势

网站值得借鉴的是逐通道滑动 MDF/MNF 及趋势图。当前 PL 内部逐通道计算 MDF，但现有结果主要输出八通道平均 MDF、平均值历史斜率及等级；仅从平均数无法恢复各通道曲线。

建议分步实现：

- 先导出或保留逐通道 MDF、活动能量和有效性，再增加 MNF、RMS 的趋势。
- LCD 显示选中通道当前值、参考值、相对变化和最近一段时间趋势。
- 只在质量合格、活动充分且任务可比较的时间段更新疲劳参考与斜率。
- 静息、动作转换、接触变化或有效通道集合改变时，显示“等待/当前不可比较”，避免把这些变化解释为疲劳。
- 疲劳等级的平滑与连续确认继续保留，但不能仅靠更长平滑掩盖输入异常。

实施前需要统一并记录频谱口径：当前 LCD 选中通道 FFT 使用最终处理信号、去均值和 Hann 窗；PL 疲劳入口还存在独立高通处理，MDF 累积范围也需核对统一。不同处理链或不同有效频带计算的 MDF，不应直接当作同一指标比较。

保留原始数据非常重要：当前 50 Hz 陷波、梳状滤波及 HP20/LP215 会改变频谱；网站示例带宽不能直接替代现有链路。工程中的相对趋势也不等于经过临床验证的疲劳结论。

### P1：激活起止、保持时间和训练反馈

在现有 LCD 动作标注、MAV 静息门控与姿态稳定策略上增加：

- 指令开始、肌电活动开始、动作识别稳定三个独立时刻。
- 每次动作的保持时长、重复次数、静息恢复时长。
- 目标动作完成率、误触发次数、动作内部跳变次数。
- 按用户实际标签统计混淆情况，保留转换段单独评价。

网站的自动激活检测支持基线阈值和最短持续时间，可以借鉴。肌电开始活动不等于某个具体手势已经开始，更不等于手部空间运动的准确起点；应避免混用这些指标。

### P2：分析与会话回顾

- LCD：逐通道 RMS/iEMG 趋势、按通道编号绘制的活动热图、选中通道频谱与趋势。
- PC：多会话并排比较、同动作片段叠加、原始与最终处理差异、逐通道质量分布、标签修订和批量报告。
- 训练报告：按完整佩戴批次留出，分别统计各动作召回率、静息误触发、稳定标签内跳变和转换延迟。
- 记录侧：保存校准、滤波、模型版本及质量事件，和 BIN/CSV 对齐。

活动热图适合我们的区域采样布局，但应使用 CH1–CH8 或经确认的位置名称，不能未经解剖定位就画成特定肌肉的真实激活。

另有一项来自项目自身的高优先级工作：EMG018 尾部异常应继续定位，考虑有版本管理的数据块校验、完整帧计数与结束标识。当前解码器能够发现部分字段/序号异常，但这不是已经修复了存储损坏原因。协议变更必须同时保留旧文件解码兼容和异常文件测试。

## 3. 不宜直接移植的部分

### 下肢脊髓映射

网站当前模块使用下肢肌肉到 L2–S2 的映射。我们的手腕/前臂区域电极不满足该解剖映射的输入条件，不能换成上肢标题后直接使用。上肢相关研究需另行建立有依据的肌肉采集与支配映射。

### 肌肉协同和贡献比的生理解释

NMF 可作为后续 PC 侧探索工具，观察八路活动模式和跨会话变化；它不是当前分类稳定性的首选补丁。区域电极、肌肉串扰和接触变化都会影响分解。没有进一步证据时应称为“通道活动模式”，不能直接等同于神经协同或独立肌肉控制。

同样，某通道 iEMG 占八路总和的比例可以叫“通道活动占比”，不应直接声称是该肌肉的力量贡献比例。

### 小波、标准阈值和网页代码

网站出现小波去噪、自动激活阈值或质量评分，不代表应立即加入在线识别主链。任何新滤波都需要验证对特征、响应时间、疲劳指标和量化模型的影响。页面公开可访问也不等于允许直接复制其代码；实现上优先复用本项目代码与已有 DSP 模块。

## 4. PL、PS/LCD 和 PC 的建议分工

| 层 | 合适的新增工作 | 可复用基础与验证重点 |
|---|---|---|
| PL | 逐通道饱和/峰值/能量计数，FFT 功率累积、MDF/MNF，必要的固定窗口统计 | 复用滤波、特征与串行共享 FFT；数值范围、位宽、数据序号、输出带宽须仿真验证 |
| PS/LCD | 质量状态与解释、校准向导、逐通道趋势缓存、有效性管理、训练提示和统计、SD 会话信息 | 复用页面、触摸分发、静息校准与记录状态机；检查渲染负载、采集服务和 SD 时延 |
| PC | Welch 高分辨率质量分析、时频图、多会话对比、批量评估、模型训练与可选 NMF | 复用现有解码、报告和训练工具；按佩戴分组验证，维护处理链与数据完整性追踪 |

MNF 可用功率加权频率与总功率计算，适合在已有频谱遍历中累积，除法放 PS 也是候选方案。是否值得搬到 PL，仍应由软件负载和资源实测决定；本次没有重新综合，不能承诺具体 LUT/DSP/BRAM 余量或时序结果。

## 5. 建议的实施次序与验收

1. 完成当前固件的下一次跨日重新佩戴测试，保存同一动作流程、标签和佩戴条件；先用现有候选模型/策略测试，再用数据做开发。
2. 增加质量页与佩戴校准记录，优先解决“这次佩戴与上次差在哪里、哪一路异常”。
3. 增加单通道疲劳趋势与有效性判定，再增加动作起止和训练反馈。
4. 补齐会话比较与记录完整性，最后评估 NMF 等研究功能。

建议后续验收包含：合成正弦/宽带噪声和可控干扰的指标校核，断路/接触变化的已标注离线样本回放，C/Python/RTL 口径一致性，LCD 截图及触摸回归，采集和 SD 连续性回归。对独立跨日数据分别报告分类、误触发、跳变和延迟，不能用同一批调参数据代替独立验证。
