# MPU 相对校准零位与肌肉协同稳定范围

固件标识：`20261031_HAND_CONTROL_HDC_DYNAMIC_IMU_ZERO_V23`。

## 操作与行为

- 保持希望作为基点的前臂姿态，点击现有 MPU 校准按钮或发送小写 `z`，静止约 1 秒；运动会重新开始静止采样窗口。
- 校准完成时，此姿态对应虚拟手掌心朝上的默认姿态和掌部旋转 0°。之后翻掌、抬臂等运动均相对此基点计算。
- 允许竖直姿态校准。MPU 六轴传感器没有磁航向参考，校准建立局部坐标，不提供绝对地理航向或手部绝对位置。
- 校准请求立即使旧旋转输出失效；静止校准过程中可显示临时相对姿态，掌部联动仍需校准有效和现有输出使能条件。
- 肌肉协同握拳训练以舒适参考的 **70%–130%（含上下边界）** 作为有效范围；LCD 与 SD CSV 的上下界一致。
- 连续抓握的五指位置插值及机械手既有标定、使能、限位、停止、断流保护沿用。

## 实现

PL 继续计算 `inverse(q_zero) * q_current`。原实现又通过校准时的重力方向旋转显示矩阵，使倾斜和掌心朝向重新进入输出；现改用固定的掌心朝上显示坐标基底。零偏学习和重力融合继续在原传感器坐标下运行。

更新姿态 ROM 并重新实现整机；PS 固件沿用姿态邮箱 ABI。生产 ARM 路径不增加软件姿态融合。原有肌电模型与参数、PL NMF/HDC、PWM 反相接口继续保留。

## 验证

- 独立浮点姿态融合与 PL Q24 定点算法比较：13,528 帧；矩阵元素最大误差 0.002197，掌部角度最大误差 1°。
- RTL 逐位回放、邮箱冻结快照、超时、断流、重新校准与序号回绕。
- RTL 和实际整机 OOC 综合网表：60°姿态重新校准后归零，反向转动 30°输出约 −30°。
- 真实固件 LCD、机械手与协同抓握回归；70% / 130% 边界、边界外一计数、动作与同窗口新鲜度约束。
- ARM 编译、整机布线时序与原有构建门禁；BOOT 分区与当前位流、应用及 FSBL 加载段一致性。
