# EMG013：调整佩戴松紧/接触后的评估

用户确认：只调整佩戴松紧或电极接触，通道位置沿用原布置。

共 967,656 帧，241.914 秒，4000 Hz；序号连续，无丢帧、倒退或重复。raw 满量程样本 0。

raw 自动质量状态 PASS；processed CHECK。状态需结合下方频谱和波形判断。全记录处理后 PC1 为 92.5%，初始静息段则为 19.1%，显示跨通道共同变化主要由记录后段支配。

变化按 CH1–8 各自计算。PC1 是差分通道共享方差占比，不是 BIAS 电压。只改变松紧/接触的对比也可能受每次佩戴位置和动作执行差异影响。
