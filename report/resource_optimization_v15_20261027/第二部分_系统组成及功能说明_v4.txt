P0: 第二部分  系统组成及功能说明
P1: 2.1 整体介绍
P2: 本系统面向上肢康复训练与肌电人机交互，以 XC7Z020 SoC 为核心构成板端闭环：前端由八对差分电极与 ADS1299 采集肌电，MPU6050 提供前臂姿态；PL 承载三类实时通路，即采集预处理链（SPI 采集、滤波、滑窗特征与 MLP 五类判决，FFT 与疲劳趋势分析）、个体化学习加速核（HDC 编码与原型运算、NMF 协同系数求解），以及 MPU姿态解算与六路 PWM 执行时序；PS 负责静息校准与佩戴适配、自学习流程与类别库管理、康复训练任务、识别来源选择与机械手目标生成、LCD 页面交互、虚拟三维手绘制、选定通道频谱与 SD 记录；DDR 作为跨域共享存储，经 HP0 服务采集与显示、HP1 服务学习运算，保存帧缓存、波形、特征与类别模型库。输出侧为触控 RGB LCD、SD 卡、隔离串口与 PC，以及五指加掌部旋转的六路机械手。总体结构如图 2-1 所示。

P5: 肌电数据进入 PL 后分为原始记录与处理分析两条支路。处理后的波形用于特征提取、五类基础动作识别和疲劳分析；特征窗口经 DMA 写入 DDR，再由 PS 提交 HDC 与 NMF 运算任务，PL 读取共享数据并返回结果。PS 根据有效类别、用户映射及 MPU 姿态生成显示和执行目标，PL 负责六路 PWM 的同步更新与保护。MPU 数据经 PL 的 I²C 接口解算后交 PS 使用；显示路径由 PS 绘制帧缓存、PL 的 VDMA 连续扫描输出至 LCD，触摸事件沿同一通道返回；raw 与处理波形按同序号写入 SD，供 PC 复核。
P6: 架构划分依据数据速率和交互复杂度。固定采样节拍、滤波与乘加运算适合在 PL 中构造可验证的数据通路；学习标签、动态类别库、页面导航和训练配置则由 PS 管理。三类解码运算均由 PL 承载，时延具有周期确定性，不受显示、触摸与记录负载影响；学习与训练流程仍由 PS 调度，兼顾灵活性与可验证性。
P7: 2.2 硬件系统介绍
P8: 2.2.1 硬件整体介绍
P9: 系统硬件整体由 Zynq-7020 开发板、隔离电源模块、采集前端、交互与执行外设四部分构成。主控器件采用 XC7Z020-2CLG400，单芯片内集成双核 ARM Cortex-A9 处理系统（PS）与可编程逻辑（PL）两类计算资源：PS 运行 ARM 裸机 C 程序，PL 采用 RTL 实现，实时运算、接口控制与人机管理在同一片 SoC 内完成，无需外扩协处理器。
P10: 隔离电源模块采用双电池分别对机械手与主体独立供电：电池供电不引入工频干扰，机械手动作时的电流波动也不会串入采集与处理电路；两部分之间的电气连接经光耦隔离，形成明确的电气安全边界。
P11: 采集前端由八对差分干电极、ADS1299 模块和 MPU6050 模块组成：ADS1299 经 SPI 接入 PL，完成八通道表面肌电采集；MPU6050 经 I²C 接入 PL，提供前臂姿态。
P12: 交互与执行外设包括触控 RGB LCD、SD 卡、隔离串口和机械手：LCD 的 RGB 显示与触摸接口均接入 PL；SD 卡与隔离串口使用 PS 外设接口，分别承担系统启动、数据记录与运行状态监测；机械手为五指加掌部旋转结构，由 PL 输出六路 3.3 V PWM 驱动。

P32: 2.3 PL 逻辑设计
P33: PL 逻辑围绕连续采集构造共享预处理主链，再按用途分支。原始数据始终保留；最终处理波形仍为带正负号的数据，整流仅用于包络与时域特征计算，避免把用于观察的波形变为单极性信号。主要路径如图 2-6 所示。
P34: 
P35: 图 2-6  采集预处理与分析数据通路
P36: 预处理与数值实现。每个通道依次经过 50 Hz 陷波、以 50 Hz 为基频的梳状滤波，以及约 20 Hz 高通和 215 Hz 低通。陷波增强基频衰减，梳状滤波抑制整数倍工频分量，带通限制运动伪迹和带外噪声。频率选择同时会损失相邻频带的肌电成分，因此保留 raw 支路用于复核。历史命名 notch50 的录制出口在当前版本中表示整条链路的最终处理结果。
P37: 滤波输出采用有符号 24 bit 格式，中间乘加扩大位宽，配合小数精度保留、舍入和饱和处理，避免直接截断导致小幅信号失真。工频滤波计算复用运算单元并按通道保存状态，后续八通道带通独立维护历史量。特征支路直接复用带通后的数据，不重复叠加带通滤波。
P38: 滑窗与特征。以每通道 400 点形成 100 ms 窗口，每接收 100 个新样点更新一次，步长为 25 ms，重叠率为 75%。窗口计算 MAV、波形长度、能量、过零次数和斜率符号变化次数，每通道五项，共 40 维。硬件 MAV 出口保存绝对值累加和，转换为均值时再除以窗口长度；能量等字段按接口约定缩放，PS 和模型输入使用一致的量纲。
P39: 窗口数据及特征带有通道编号和序号。原始波形、处理波形、特征与分析结果分别缓存，使显示、记录和推理能够共享同一采样来源。下游出现背压时遵循 ready/valid 握手，避免未接收的数据被提前覆盖；连续性异常则由 PS 在任务入口识别，防止缺失窗口进入学习或保持计时。
P40: 轻量网络与稳定判决。基础动作网络采用 40→64→32→5 的全连接结构，输出放松、张手、握拳、屈腕和伸腕。权重采用 INT8，偏置与累加采用 INT32，隐藏层执行 ReLU 和重新量化。权重存入片上存储器，乘加单元按层和神经元顺序复用，以资源可控的串行运算满足 25 ms 特征更新节拍。
P41: PL 控制策略模块计算定点 Softmax、活动门控和连续窗口判决。静息校准由 PS 发起，PL 丢弃过渡窗后统计基线，形成活动阈值。活动幅值与类别可信度分别判断，类别变化需时间确认，输出附带有效及新鲜度状态，避免将低幅噪声的最高分直接视为动作。
P42: FFT 与疲劳趋势。PL 疲劳分析对八通道共享一套 2048 点顺序基 2 FFT 核，采用双缓冲保存输入，复用蝶形运算。4 kSPS 对应 512 ms 的变换区间，频率间隔约 1.953 Hz。各级定点缩放控制溢出，功率谱用于累计频带能量，求出累计能量达到分析带一半时的中值频率 MDF，并输出能量及分带信息。
P43: 疲劳计算仅接收活动达到阈值、类别稳定且未削顶的有效发力窗口。建立有效发力基线后，对 MDF 进行跨窗平滑，以相对下降幅度和连续确认形成趋势等级。持续同类收缩期间保留已确认的较高等级，防止瞬间频谱回升造成反复下降；放松、类别改变或数据无效时重置该次收缩的趋势状态。基线不足时显示等待，不把缺少活动的噪声频谱解释为重度疲劳。
P44: LCD 的详细频谱另有一条 PS 辅助路径：对当前选定通道的 2048 点处理波形去均值、加 Hann 窗并执行定点 FFT，随后按屏幕像素合并频点、自动归一化并留出顶部余量。PL 路径服务连续疲劳分析，PS 路径服务交互式单通道观察；二者的用途和加窗处理不同，不能将 LCD 图形直接等同于 PL 疲劳核的内部谱值。
P45: 机械手执行逻辑。六路 PWM 分别控制拇指、食指、中指、无名指、小指与掌部旋转。PS 一次提交完整目标，PL 在同一帧边界原子更新各轴，输出周期为 20 ms。协议边界为 500–2500 μs，实际各轴还受到已保存标定范围约束；每帧最大脉宽步进为 20 μs，减缓目标突变。250 ms 链路看门狗与使能条件共同控制输出。
P46: 复位使用保存的放松映射与掌部零位，同帧启动各轴回位并持续保持，未标定时不启动输出。当前机械手没有位置或力反馈，PWM 仅代表控制目标，停止 PWM 也不等同于切断舵机电源。
P47: HDC 与 NMF 运算核。个体化学习与肌肉协同共用 PL 学习加速器。该核工作于 100 MHz，经 AXI 主接口读取 DDR 中的描述符、特征与模型，完成计算后写回结果。PS 不再承担正式板端 HDC 高维编码、原型相似度或 NMF 系数求解，仍负责样本选择、任务提交与结果展示。
P48: 
P49: 图 2-7  HDC 学习验证与 NMF 协同求解的职责划分
P50: 超维编码与在线原型。HDC 使用八通道 MAV，将各通道按训练尺度量化为 16 级，结合通道向量和等级向量生成 2048 维二值超向量。编码通过绑定与投票聚合保留通道活动分布；带标签的完整学习试次用于累加带符号原型，采用饱和更新限制数值范围。推理时与全部类别原型计算点积，输出最佳类别、次佳类别与分离裕量；裕量反映类别分离程度，不作为概率置信度。
P51: 随机向量存于 BRAM，类别原型采用带符号 16 bit 数据并存于 DDR，以适应自定义类别扩展。计算状态机分步执行读取、编码、更新或点积和结果写回，复用运算资源。类别数量不设固定的三个自定义槽位，但受到 DDR 容量和全类推理时间限制；推理超过应用时间预算时不接入联动。
P52: 肌肉协同求解。NMF 用固定的 8×3 非负基矩阵表示八通道活动，基矩阵来自 EMG008、009 的离线拟合。每个窗口输入八路平均绝对值，以投影初始化三路系数，再执行八轮乘法更新，得到三路协同系数、相对占比和重建残差。基矩阵为 Q15，系数为 Q8，内部复用乘法器和迭代除法器。在线更新的是系数，基矩阵本身不在板上重新学习。
P53: PS 对协同系数平滑后显示相对用力变化，并以一次舒适抓握建立个人参考，用于握拳任务的参考值 ±20% 目标带。协同系数受佩戴与接触状态影响，不直接等同于牛顿或公斤力；当前也未将其作为连续抓握力闭环驱动机械手。
P54: 2.4 PS 程序与应用流程
P55: 运行组织与交互。PS 程序采用 ARM 裸机 C 实现，通过持续服务采集、页面交互和后台任务组织系统。上电完成外设、DMA、帧缓存与 SD 初始化后，进入实时监测；各页面按监测分析、个体化学习、康复训练和机械手设置组织，进入相关模式时检查所需数据与配置，退出或切换时解除不应持续的执行状态。
P56: RGB LCD 使用 DDR 帧缓存，PS 绘图后由 PL 中的 VDMA、视频输出和时序模块连续扫描显示；GT911 返回触点，PS 完成按钮、滑块和页面路由。界面集中显示动作、分数、波形、频谱、通道质量、协同与疲劳状态。绘图和选定通道 FFT 的较长循环中插入采集服务，避免显示运算长期占用 CPU 而造成 DMA 缓冲积压。
P57: 校准与佩戴适配。通道检查以处理后的波形建立约 3 s 静息参考，将工频及谐波残留、突变、削顶相关信息和异常幅值汇总为 0–100 分与 A–D 等级，帮助用户比较通道并调整接触。评分属于信号质量启发式评价，不是电极阻抗实测；处理后的低噪声也不能独立证明原始前端没有饱和。静息校准则由 PS 引导用户放松并触发 PL 统计，完成后使用新的活动阈值。
P58: 佩戴适配针对腕部六通道的环向次序变化，按已确认的 4、1、2、3、5、6 布局比较六种循环置换，使用独立验证样本比较原模型与候选方案。候选未通过时继续使用原方案，不因用户完成采样就强制替换。该功能修正有限的环向对应变化，不能自动消除电极任意移动、断路和发力模式差异。
P59: 自学习与模型管理。自定义手势由用户选择标签后采集，每类完成三轮学习和两轮独立验证，每轮采集 40 个有效窗口；动作切换后先丢弃过渡窗，完整试次通过检查后才提交。验证时冻结原型，逐类正确率达到 80% 门槛后，模型才允许进入联动。非放松类别连续三窗、放松连续六窗确认，减少切换抖动。无标签的自由动作不会自动写入学习原型。
P60: 类别库在 DDR 的两块 32 MiB 区域间进行动态分配与提交，名称及虚拟手、机械手映射随类别管理。追加类别保留已有映射，全部重新学习则清空相应库。当前 HDC 模型与自定义映射为本次上电 RAM 数据；SD 波形记录和训练日志已经支持，但不据此宣称实现了断电后的 HDC 模型恢复。基础 MLP 与 HDC 由用户选择来源，评分口径分别显示为概率置信度与分离裕量。
P61: 训练任务与反馈。康复训练围绕现有稳定识别动作提供单动作和四动作组合任务，支持设置次数、保持时间及组间休息。任务按“静息校准—放松准备—目标提示—动作保持—恢复休息—训练结果”推进，组合模式按预定次序切换张手、握拳、屈腕与伸腕。组间休息结束后由用户确认继续，暂停恢复时重新检查基线与有效数据。

P63: 图 2-8  单动作与组合康复训练流程
P64: 只有目标类别有效、序号连续且满足稳定条件的窗口才累计保持时间，识别中断与超时分别记录。结果包括完成率、识别响应时间、保持中断和协同用力情况；响应时间以提示到识别确认计时，包含滑窗、分类和稳定判决延迟，不能直接解释为生理反应时间。疲劳趋势作为训练状态提示，不独立形成临床结论。握拳可额外使用个人协同参考目标带，引导较一致的相对发力。
P65: 虚拟手与实体机械手映射。虚拟手采用透视投影与深度关系绘制 22 个关节的姿态，基础类别对应预设动作，自定义类别可独立编辑各关节角度并保存。切换时进行平滑插值，MPU 姿态控制前臂和手的整体方向，表现远近和翻掌变化。单个前臂 MPU 测量方向，肘部位置和空间运动依靠约束模型推算；当前虚拟手是识别类别到姿态的映射，并非连续肌电关节角回归或完整空间位置测量。
P66: 实体机械手独立保存五指 PWM 映射，掌部旋转跟随 MPU。由于机械手没有独立屈伸腕轴，屈腕和伸腕不被强行解释为掌部旋转。标定和映射页通过滑块与微调按钮编辑，允许在明确进入标定状态后同步预览；正常联动还需有效标定、有效模型、已保存映射与显式使能。学习新手势并不会自动驱动机械手。
P67: 虚拟姿态与六路脉宽独立存储。未映射类别在虚拟端提示并回到放松，实体端执行映射与新鲜度保护。编辑虚拟手、学习手势或开始康复任务均不自动启用 PWM。
P68: 数据记录。SD 将同序号 raw 与处理波形成对写入 EMGxxx.BIN，附人工动作标签；康复与自学习验证分别生成 RHxxx.CSV、HDxxx.CSV，供 PC 复核。
P69: 2.5 PL 与 PS 协同及接口
P70: 原始波形、处理波形、特征和分析结果经独立异步 FIFO、AXI DMA 及 HP0 写入 DDR；LCD VDMA 经 HP0 读取帧缓存。HDC 与 NMF 通过 HP1 访问任务和模型，分散端口压力，但仍共享 DDR 带宽。
P71: 表 2-2  主要 PL PS 交互接口
P72: 任务交接。PL 输出带序号的特征后，PS 检查窗口完整性与时效，将输入及描述符写入共享区，执行屏障后发命令。加速器完成 NMF 或 HDC 运算并写回结果，PS 确认成功后更新显示及稳定类别；已启用联动时再提交完整目标，由 PWM 帧边界执行。
P73: 学习核逐次检查地址对齐与范围，AXI 错误使任务失败。超时后隔离核并排空未完成事务，避免迟到响应污染下一任务；异常时不回退 ARM 软件运算。推理的 20 ms 接入预算属于调度保护条件，并非板上实测时间。
P74: 跨域与并发运行。采集域为 25 MHz，AXI 与学习核为 100 MHz。FIFO 以 Gray 指针和两级同步跨域，复位异步置位、同步释放；配置采用请求应答握手。原始与处理流各保留 4096 字 BRAM 缓存，同步读预取，接收后再推进指针。时钟与 LCD 输出分别约束，接口例外限定于实际异步关系。
P75: 各缓冲区独立管理所有权。无效识别不计时，未验证模型不联动，未标定或未使能时不执行。序号、完成状态与看门狗共同约束板端闭环。
