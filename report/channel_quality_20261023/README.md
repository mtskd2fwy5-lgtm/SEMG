# LCD 通道质量检查（最终处理波形）

用于佩戴后检查八路通道、辅助调整电极接触。入口：LCD 顶部“数据”；“分析指标”切回原 MAV 页面，“通道检查”返回本页。

## 使用

1. 前臂放松，点击“放松采参考 3s”，保持三个完整一秒窗口。八路全部完成才采用参考。
2. 点击通道卡片，查看该路静息 RMS、参考 RMS、峰值因子。每次调整一个通道的松紧/接触，然后保持放松至少 1–2 秒比较。
3. “通道波形”“通道频谱”打开现有页面，使用该通道的最终有符号处理波形。
4. 最后做目标动作检查：静息平稳、动作时有可重复变化。幅度越低不代表接触越好；近乎平线、松动或断路也可能很安静。
5. 参考仅驻留 RAM，重启后重采；中断、缺失或超时会提示参考未完成。

## 计算与解释

- 唯一输入为 type=5：PL 50 Hz 陷波 → 梳状滤波 → 20 Hz 高通 / 约 215 Hz 低通后的正负波形。监测和 UART 录制模式均更新。分类、录制数据、滤波器及 PL 不变。
- 八通道各自每 4000 个连续样本（1 秒）发布一次结果，不把重复样本计入窗口；序号缺口、倒退或停顿超过 1.5 秒重置窗口。超过 1.5 秒无新样本显示无新数据。
- RMS：去直流后的标准差，单位为 ADC 计数，保留整数。仅在用户实际放松时解读为静息噪声。
- 峰值因子：去直流峰值 / RMS。超过 10 提示尖峰。数值和阈值为工程筛查规则，不是接触阻抗测量。
- 定频残余能量：1 秒矩形窗相干 DFT 在 50、100、150、200 Hz 四个频点的双边功率之和 / 去直流总功率，显示百分比；达到 10% 提示疑似工频偏高。它包括这些频点上的 EMG 能量，不等于已经分离的纯干扰。
- 本实现不是截图中的 Welch PSD、谱底扣除或宽带 SNR。不会据此输出 A/B/C/D 综合等级。它不覆盖偏离标称频率的全部旁带、60 Hz 电网及 250 Hz 以上原始谐波，不能用低占比证明工频已完全消失。
- 与三秒参考相比 RMS > 3 倍提示“噪声或活动上升”，小于 1/4 提示“幅度下降，检查”。这些条件与用力、姿势也有关，不能直接证明电极断路。
- 处理波形达到 24 位范围的 99% 提示接近满量程。这是对最终输出的检查，无法追溯前级 ADC 已发生的削顶。
- 原始低频漂移、原始饱和、阻抗和导联脱落均不能由已滤波数据可靠判定。没有自动屏蔽通道、改变模型或放松适配验收门限。

## 实现与验证

`sw/ps_uart_print/channel_quality.h` 为整数流式统计，使用少量固定状态，四个正余弦点积/样本，无八路 FFT/波形缓存。质量页复用现有 LCD 绘制及波形/频谱路由。

- `build/scripts/run_channel_quality_test.ps1`：已知 RMS/正弦/四个工频频点、偏置、零输入、正负满量程、序号环绕/缺失/重复、时间环绕/中断、来源/通道/保留位拒绝、缺失通道不完成参考。
- 独立 NumPy FFT/标准差对照：合成信号及 EMG008、EMG015、EMG018_validprefix 各前 24 秒；结果见 numeric_validation.json。真实数据 RMS 最大误差 < 1 ADC 计数，四频点占比最大误差 < 0.16 个百分点。
- 实际固件 LCD host 测试：800×480 和 1024×600，八路指标、异常提示、三秒参考、过期状态、触摸选择、波形/频谱跳转及帧缓冲一致性。
- UART 真实录制路径：raw/processed 两种录制选择均只从 type=5 更新诊断；监测路径 raw 不进入诊断，二进制串口内容回归通过。
- ARM 裸机编译；仅已有 Xilinx ff.c 的 unused vol 警告。

候选 BOOT_20261023_QUALITY_V1.BIN 已打包；PL 分区与当前 bit 全字节一致，PS 加载段与当前 ELF 全字节一致（artifacts.json）；不覆盖既有 BOOT.BIN，不自动写入启动卡。尚未在实物上验证新增诊断的刷新时延、CPU 负载和电极调整效果。
