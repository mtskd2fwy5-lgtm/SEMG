## 重佩戴信号变化

raw 质量页的 CHECK 来自跨通道共享成分较强的提示，不是丢帧或 ADC 削顶告警；也不是 BIAS 电压的直接测量。初始静息 raw 第一主成分约占 98.4% 的通道方差，EMG010 约 98.5%；处理后该比例从 EMG010 的 35.4% 上升到 EMG011 的 55.3%，提示处理后仍有更多跨通道共同变化，需结合电极接触和共模路径观察。
全记录稳定段 raw 的 50 Hz 基波占 20–450 Hz 功率约 32.2%–87.5%；处理后降至约 0.13%–0.36%。100–450 Hz 谐波处理后约占 0.9%–3.7%。
用户确认 CH6 的一片差分电极断路。其处理后 clean RMS 在五类标注中的类别中位数为 7.70–7.95 counts，几乎不随动作变化，与断路情况相符；因此分类主结果剔除了 CH6。
100 ms 功率集中度提示需复核的片段包括：wrist_flex 23.54–34.22s (CH4); wrist_flex 69.49–80.76s (CH1, CH4); rest 80.76–85.68s (CH4); open_hand 117.57–123.29s (CH4); rest 142.17–145.48s (CH4)。这些可能是短时动作或电极/导线瞬态，不能直接据此断定为伪迹；训练时可先排除这些片段再比较。

## EMG008 模型测试解释

- 将 EMG008 的已标注采集数据作为唯一训练来源，按 EMG010 使用的基线流程重新拟合，再测试 EMG011；主结果剔除 CH6，仅用其余 7 通道的 MAV/WL/Energy/ZC/SSC，100 ms 窗口、25 ms 步长，StandardScaler + MLP(64,32)，五个随机种子。仓库现存的 baseline joblib 是 NinaPro DB5 模型，并非 EMG008 专属保存模型。
- 剔除 CH6 后，跨佩戴准确率比含断路通道的结果提高 18.4 个百分点，宏 F1 提高 24.7 个百分点；张手召回 96.2%，伸腕 71.4%，握拳 100.0%，屈腕 98.1%。仍需关注静息召回仅 73.2%。
- 剩余主要混淆是伸腕被判为握拳；静息样本也会被判成握拳或伸腕。EMG011 内按动作段分组的留出结果较高，但只有 3–4 个独立动作段/类别。
- 用户已确认 CH6 的一片差分电极断路，因此此前 8 通道分类结果不能代表有效 8 通道信号；主结果在训练和测试两侧都移除 CH6 的五组特征。EMG008 与 EMG011 都有五类动作标注；EMG011 的独立动作段分别为张手 3 段、握拳 3 段、屈腕 4 段、伸腕 3 段。窗口重叠，因此准确率不应视为独立样本统计。
- EMG011 内部验证把完整动作段留出，估计的是本次佩戴内部可分性；跨佩戴低分而内部验证高分，表示新佩戴的特征分布变化明显，应在新佩戴后校准或将多次佩戴数据纳入训练。
