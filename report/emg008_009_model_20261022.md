# EMG008/009 多佩戴综合模型

生成日期：2026-10-22。模型为开发候选，沿用当前 PL 特征与分类器接口。

## 数据范围

- 训练：EMG008、EMG009、EMG012、EMG013、EMG014、EMG015、EMG016。
- 最终完整佩戴留出：EMG017，没有参与模型拟合、标准化或训练质量阈值计算。
- 未纳入训练：EMG010（报告显示 CH6 对动作几乎无响应）；EMG011（已确认 CH6 电极断路）。
- EMG015 是纯静息数据，只补充静息类，不提供动作类别。
- 仅使用 `processed` 波形：50 Hz 陷波、50 Hz 梳状滤波、20 Hz 高通和 215 Hz 低通。

## 信号和模型契约

沿用项目 `tools/train_baseline.py` 的八通道 MAV、WL、Energy、ZC、SSC 特征；采样率 4 kHz，400 样本窗口、100 样本步长（100 ms/25 ms），StandardScaler + MLP(64,32)。每段标签边缘各去除 1 秒。训练时按动作类窗口中位数下采样放松类。

为降低报告中极端尖峰对权重的影响，训练阶段剔除任一通道 MAV 超过同一记录、同一标签、同一通道中位数 12 倍的窗口。阈值只由训练记录计算；完整记录留出窗口保持原样。被剔除数：EMG008 0、EMG009 2、EMG012 385、EMG013 1482、EMG014 252、EMG015 0、EMG016 223。该规则是保守的幅值异常筛选，不会识别所有电极接触问题；保留的窗口仍可能含伪迹。

## 验证

按完整 CSV 记录留出，每折重新拟合 StandardScaler 和 MLP。EMG008、EMG009 属于同一佩戴，因此这两折主要衡量同佩戴记录差异。跨佩戴的 EMG017 只在最终模型上测试一次。

| 留出记录 | 窗口准确率 | 宏 F1 | 说明 |
|---|---:|---:|---|
| EMG008 | 88.2% | 87.6% | 与 EMG009 同一次佩戴 |
| EMG009 | 97.5% | 97.3% | 与 EMG008 同一次佩戴 |
| EMG012 | 77.4% | 78.1% | 重佩戴 |
| EMG013 | 65.1% | 68.2% | 重佩戴，CH6 幅值异常 |
| EMG014 | 70.4% | 64.4% | 重佩戴，CH4 有突发脉冲 |
| EMG015 | 99.9% | 50.0% | 纯静息，只能评估静息识别；准确率不代表五类效果 |
| EMG016 | 80.0% | 79.7% | 重佩戴，存在 CH6 瞬态 |
| **EMG017 最终留出** | **88.9%** | **90.3%** | 完整记录，未参与训练 |

EMG017 各类召回：静息 69.7%、张手 100.0%、握拳 99.9%、屈腕 99.5%、伸腕 100.0%。类别 F1 和混淆矩阵见机器可读指标文件。各窗口有 75% 重叠，窗口数不是独立动作次数；EMG017 也只是一个新佩戴，不能据此承诺所有佩戴都达到该成绩。

多佩戴训练提升了 EMG017 相对 008/009-only 候选的表现，但静息仍有约 30% 被识别为动作，主要落在握拳和伸腕。训练/留出验证支持作为实验候选，不构成临床康复性能验证。请先离线评审后再考虑量化导出或替换板载模型。
