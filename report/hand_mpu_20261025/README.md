## 功能划分

| 实际机构 | 自动控制来源 | 设置 |
|---|---|---|
| 轴 0，掌部/基座旋转 | MPU 姿态相对零位的前臂纵轴旋转 | 逐轴标定脉宽下限、上限；不属于动作映射 |
| 轴 1–5，五指 | PL 原模型，或显式选择的 PS HDC 冻结模型 | 放松、张手、握拳、自定义 1–3，各存一组五指目标 |
| 腕屈伸 | 无对应机械自由度 | 保留识别和训练；机械手保持此前五指目标 |

轴 0 仍需标定，这是舵机脉宽范围标定，不是腕屈伸标定。映射页不再轮选屈腕/伸腕，不允许手动编辑轴 0 的动作目标；原配置中的腕动作行在上传时删除。旧 SD 配置格式/CRC 保持兼容，旧动作轴 0 值不参与自动执行。

## LCD 操作

1. 设置 → 机械手 → 逐轴标定：分别完成旋转轴和五指的脉宽范围。修改任一限值后要重新确认动作映射。
2. 动作映射：轮选放松、张手、握拳、自定义 1–3；选手指，用 ±10/±50 us 编辑，点“记录本轴目标”，再点“确认五指映射”。自定义槽位须对应本次学习时的实际手势。
3. 完成 MPU 零位校准。用户确认旋转舵机总行程 270°，实测 500–2500 us 对应 0–270°；按用户最终选择，零位设在绝对 45°，相对左旋最多 45°、右旋最多 225°。公式为 `500 + (相对角度 + 45) × 2000 / 270` us：左限约 500 us，零位约 833 us，右旋 90° 约 1500 us，翻掌 180° 约 2167 us，右限 2500 us。输出仍夹在已标定脉宽上下限内；若限值更窄，可用角度也相应缩小，不会把窄区间重新拉伸成 270°。
4. 点“来源 PL / 点击切换”或“来源 HDC / 点击切换”选择来源。停止状态才可切换，不能运行中混用两个分类器。
5. PL 来源：需确认放松、张手、握拳三行映射，点“启用 PL 联动”。五指由原模型的稳定决策控制。腕动作保持上一个有效五指目标；无前一目标时使用放松。
6. HDC 来源：先在 HDC 自学习页完成原五类及选定自定义槽位的采样和独立验证，再进入机械手页设置对应映射。各类必须完成 80 窗验证且每类正确率达到 80%；全部可执行类别都有映射后，等待稳定手势，点“启用 HDC 联动”。
7. 停止输出、离开机械手页、打开导航菜单、开始录制/重新校准等会停止联动；重启、读取配置均不自动恢复输出。

HDC 在机械手页面继续计算实时预测。原肌电监测/训练仍采用既有 PL 原模型；本轮没有把 HDC 编码、学习或推理迁入 PL。中文手势命名也未在本轮实现，仍用自定义 1–3 标识。

## MPU 与 HDC 处理

MPU 使用当前融合四元数相对校准姿态，围绕传感器 Y 轴（朝手肘）做 swing/twist 分解。旧 PL pitch 来自有 ±90° 折返的倾角，不能用于连续翻掌，因此本轮机械手不采用该旧角。角度通过已有正弦查表反求，跨 ±180° 连续展开后限幅到 -45°～+225°；抬臂的 swing 不单独改变旋转目标。接近 twist 奇异位姿时判为无效并停止联动。

MPU 有效数据需在 100 ms 内；PS 每 20 ms 最快发送一次旋转目标，静止时 50 ms 重发。按左手 X 朝小指、Y 朝肘部的既有安装方向处理，角度正向对应脉宽增加，定义为右旋。机构的实际左右方向、零位安装与可达角度仍需卸载小步确认。500–2500 us 是用户实测的电机对应关系，不是本次软件测试替代实测给出的参数；带机构后仍以标定的安全区间为准。

HDC 的 80% 是首轮工程启用门槛，不是临床指标或泛化准确率。实时桥接要求分数间隔至少 2%（非概率）、至多一路量化超范围，动作连续 3 窗、放松连续 6 窗确认。短暂类别切换最多保留前值 8 窗；不合格预测、序号断裂、模型重测或超时使 HDC 来源停机，须手动重新启用。

HDC 分类和 MPU 旋转分别通过已有 GPIO5 请求/ACK 邮箱送给 PL，均保持负载到 ACK；无新增 GPIO 或引脚。PL 独立检查 host、原 PL 决策、MPU 旋转和 HDC 决策的新鲜度（250 ms），检查目标脉宽范围、映射存在和模式互斥，再交给既有 20 ms 帧、每帧 20 us 限速的 PWM 原语。

## 邮箱补充

原 opcode 0–8 保持，新增：

| opcode | 含义 |
|---|---|
| 9 | value 为已映射且在轴 0 标定范围内的 MPU 脉宽；刷新独立旋转看门狗 |
| 10 | row 为经 PS 桥接确认的 HDC 类别；只允许停止/HDC 模式，不能覆盖 PL 模式 |
| 11 | 显式启用 HDC 自动模式；须先有新鲜的 MPU 与 HDC 输入 |

状态 mode：0 关闭，1 单轴测试，2 PL 原模型，3 PS HDC。mode 3 的类别状态报告 HDC 执行目标；mode 2 中 5–7 仍视为非法原模型类别。两个自动模式中的腕类均不作为姿态行执行。STOP 使 MPU/HDC 租约失效，后续启用必须重新提供输入。
