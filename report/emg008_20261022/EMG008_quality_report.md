# EMG008：隔夜重新佩戴评估

分析日期：2026-10-22。源文件：`F:/EMG008.BIN`。

## 结论

这份记录很有价值：它来自隔夜重佩戴，且这次没有使用 EMG007 佩戴时用过的导电凝胶。处理后静息频谱与 EMG007 相近，说明新版固件面对这次重佩戴仍能输出稳定的有符号波形；本次实际处理链路、帧连续性和量程检查也通过。

我也用 EMG007 训练了与项目基线相同的 5 类窗口特征和 MLP，在 EMG008 上整份独立测试。这次重佩戴测试的平均窗口准确率约 **79.9%**、宏平均 F1 约 **71.7%**；伸腕召回率只有约 **17.9%**，大量伸腕窗口被判断成握拳。准确率受放松窗口比例影响，不能据此认定五类识别已经可靠。EMG007 训练数据含凝胶，EMG008 不含凝胶，所以这是对跨晚和本次佩戴条件变化的联合检验，不能单独证明凝胶是误差原因。

- 4000 Hz、8 通道、610894 帧，共 **152.7235 秒**；无不完整尾帧。

## 新版处理输出和信号质量

实际保存波形与项目整数 `ProcessedSignal` 参考模型核对。对记录开头、中段和末段每路各取局部预热后的区间，最大误差不超过 **2 ADC counts**；滤波模型因此与文件内波形相符。processed 有符号值同时包含正负样本，未被整流成包络。

两路 raw 和 processed 都没有 ADC 数字满量程样本。raw 峰值最高约为满量程的 **18.7%**。这说明没有数字 ADC 削顶，但不能据此确认模拟前端共模或 BIAS 状态正常。

稳定动作与放松段加权后，raw 的 50 Hz RMS 为 67.6–199.2 counts，processed 为 0.9–1.9 counts，陷波及组合链路有效。processed 中 50 Hz 邻域占 0.10%–0.18%，100–450 Hz 谐波邻域合计 RMS 为 3.0–8.6 counts；谐波没有完全消失。0.5–20 Hz RMS 从 raw 的 20.2–158.8 counts 降至 processed 的 2.9–7.0 counts，慢漂明显降低。

raw 图仍可见各通道基线在整段中缓慢大幅移动；processed 图中的放松基线则稳定在零附近。基线变化与这次的干电极条件相符，但仅凭两份不完全受控的记录，无法将变化归因于凝胶、电极阻抗、运动或某个电路因素。

### 与 EMG007 的初始放松对比

为了与 EMG007 采用相同窗口，取两份记录 **1–7 秒**的放松段，以同样的 8192 点 Welch 参数比较。raw 的 50 Hz 变化随通道不同，EMG008 相对 EMG007 约 −5.2 到 +5.9 dB；不是整齐地全部变好或变差。虽然采集条件包含“有胶/无胶”的差别，也不能将这组变化单独归因于凝胶。

processed 的 20–450 Hz 放松 RMS 为 CH1–8：**6.75、7.36、10.50、6.85、8.04、8.22、9.30、8.27 counts**。相对 EMG007 的 processed 放松 RMS 变化约 −0.8 到 +0.8 dB，整体很接近。这说明新版滤波后的静息幅度对这一次重新佩戴较稳定，但不是肌电生理信噪比或动作识别性能相同的证明。

## 动作响应

相对于每段动作紧前的放松段，去除 50 Hz 及谐波邻域后的 20–450 Hz RMS 比值如下。数值是活动幅度比，不是生理 SNR：

| 动作 | 稳定突出的通道 | 三次动作中相对放松的幅度比范围 |
|---|---|---|
| 张手 | CH3、CH5、CH6 | CH3 4.2–9.2×，CH5 6.7–12.3×，CH6 3.5–7.5× |
| 握拳 | CH1–4、CH7 | CH1 7.7–11.2×，CH2 7.0–9.9×，CH7 5.4–7.9× |
| 屈腕 | CH3、CH8 | CH3 4.3–9.8×，CH8 6.4–7.4× |
| 伸腕 | CH4、CH6–8 | CH6 4.1–7.8×，CH7 2.7–4.4×，CH8 2.8–5.8× |

相比 EMG007，隔夜后各动作仍有可读的通道响应，但幅值比例有明显差异，尤其通道贡献有所变化。因目前只有一次无凝胶重佩戴，不能据此判断这种差异普遍由佩戴还是凝胶造成。

本次 100 毫秒窗口检查没有发现“少数高能窗口贡献超过一半整段功率”的通道；这比 EMG007 的 CH6 极端瞬态情况好。不过动作边缘仍可见短尖峰，筛选窗口时仍须避开边界。

## EMG007 训练、EMG008 隔夜测试

为检查跨晚可迁移性，使用已确认的 4 kHz `processed` 数据，不重复滤波。沿用项目基线实现 `tools/train_baseline.py` 的 `MAV/WL/Energy/ZC/SSC` 八通道特征、400 样本（100 毫秒）窗口、100 样本（25 毫秒）步长、StandardScaler 与 MLP(64,32)。每段首尾各去 1 秒，窗口不跨动作段；模型只在 EMG007 上训练，EMG008 全部用作独立重佩戴测试。平衡训练放松类；随机种子 0–4 重复 5 次，只衡量初始化变化，不是 5 次新的数据采集。

| EMG008 测试类别 | 五个模型的平均召回率 | 平均类别 F1 |
|---|---:|---:|
| 放松 | 100.0% | 96.8% |
| 张手 | 62.7% | 75.1% |
| 握拳 | 97.6% | 79.5% |
| 屈腕 | 95.9% | 77.9% |
| 伸腕 | **17.9%** | **29.0%** |

总体窗口准确率 **79.9% ± 4.2%**，宏平均 F1 **71.7%**。伸腕窗口主要被分成握拳；单个随机种子的矩阵中，669 个伸腕窗口只有 78 个判断正确，390 个被判为握拳、117 个判为屈腕、84 个判为放松。故总体准确率掩盖了关键类别失败。

如果只从 EMG007 训练数据中排除先前标记的 CH6 瞬态窗口，EMG008 平均准确率为 78.6%、宏平均 F1 为 68.2%，伸腕平均召回率降至 6.7%。这项对照只提示当前结果对训练样本筛选和模型初始化敏感；它不证明保留伪迹更好，也不证明这些手工排除窗口已经足够。

测试集中相邻窗口重叠 75%，同一动作段会贡献许多相关窗口，因此 **79.9% 不是 4104 次独立动作的准确率**。目前测试只有一个隔夜重佩戴和三次动作重复；它足以暴露伸腕泛化短板，不足以宣称模型可靠。

## 对训练的判断

可以用 EMG007 和 EMG008 继续做**开发阶段训练与独立重佩戴验证**，但现在不应把五类模型视为完成或上线。下一步应优先改善伸腕与握拳的区分，保持佩戴和导电介质条件一致，增加不同日期的完整重复佩戴，再按整次佩戴划分训练与验证；不能把重叠窗口随机拆分后报告成跨佩戴性能。

如果产品会允许干电极和凝胶两种佩戴条件，需要把两类条件都纳入训练和独立测试，并分别汇报结果。本报告不能认定无凝胶有害或有益，也未测量 BIAS 和输入共模。
