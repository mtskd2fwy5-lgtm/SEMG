# 自学习肌电意图解码康复训练系统

## 作品简介

本作品面向上肢康复训练与肌电人机交互，基于 XC7Z020 SoC 构建表面肌电意图解码与康复训练平台。系统通过ADS1299采集八通道肌电，在PL端完成SPI驱动、工频及谐波抑制、数字滤波、整流、滑窗分段、时域特征、FFT频谱分析、轻量神经网络推理、超维计算个体化在线学习及NMF肌肉协同系数求解，识别常见及自定义手势，计算中值频率并评估疲劳趋势。PS端负责静息校准、佩戴适配、学习引导、模型存储及任务管理，并以触控 RGB LCD 为交互平台，显示动作置信度、波形、频谱、通道质量、肌肉协同及疲劳反馈，支持SD卡记录、动作标注和自定义手势映射。康复训练支持单动作与组合任务，设置次数、保持及休息时间，利用肌肉协同反馈相对用力变化，结合完成率、稳定性及识别响应评估训练表现。识别结果与MPU姿态驱动虚拟三维手；PS生成映射目标，PL输出六路PWM驱动五指与掌部机械手，实现抓握、掌部旋转及复位。PL承担实时处理、在线学习与机械手驱动，PS统筹交互、分析与训练管理，构建肌电采集、边缘推理、虚实运动及康复反馈闭环，体现FPGA 在低延迟生物信号处理、边缘智能和康复人机交互中的应用价值。

## 当前版本

当前软件、硬件和启动镜像版本为 `20261026_HAND_CONTROL_HDC_DYNAMIC_V13`。

V13 在已验收的 PL NMF/HDC、疲劳分析、机械手控制和康复训练基础上，补齐了自定义 HDC 手势的虚拟手映射：

- 虚拟手支持 22 个关节角度，包含手腕、拇指和四指的屈曲、侧向展开及末端关节。
- LCD 提供预设姿态、滑块和 `±1°` 微调，保存/清除映射后立即用于虚拟手预览。
- 实时监测页可切换 MLP 或 HDC 识别来源；HDC 使用经过验证的稳定类别，避免单窗口跳变。
- 虚拟关节角度与机械手六路 PWM 映射独立保存。编辑虚拟姿态、切换来源或手动预览不会自动启动机械手 PWM。
- MPU 姿态继续控制虚拟手整体方向和掌部旋转；机械手页面保留独立标定、映射、复位、停止和故障保护。
- HDC 类别和虚拟映射当前保存在本次上电的 DDR/RAM 中；断电后需重新建立或加载模型，SD 模型持久化尚未接入。

操作说明和验证证据见 [V13 虚拟手映射](report/virtual_mapping_20261026/README.md)。PL 在线 NMF/HDC 的接口、资源和时序见 [V12 PL 学习加速](report/pl_learning_nmf_20261026/README.md)。

## 系统分工

### PL（FPGA 逻辑）

PL 以确定时延运行八通道采集和处理链：ADS1299 SPI、工频及谐波抑制、数字滤波、整流、滑窗特征、FFT/疲劳支路、基础动作判决、NMF 肌肉协同系数求解、HDC 编码/原型更新/相似度推理，以及六路 PWM 输出保护。

NMF 和 HDC 的数值计算已经迁入 PL。PS 只负责逐窗调度、训练流程、模型地址和结果管理，不在生产 ARM 路径中用软件算法替代 PL 结果。运算失败、超时、数据过期或验证未通过时，结果会失效，机械手不会采用该结果。

### PS（ARM 裸机）

PS 负责静息校准、佩戴适配、学习引导、HDC 试次管理、DDR 模型生命周期、验证评分、LCD/触摸交互、SD 记录、康复训练、通道质量和数据分析。PS 接收 PL 的最终结果，并将稳定类别分别送给虚拟手显示和已明确启用的机械手映射。

### LCD、MPU 与机械手

LCD 入口页面包括实时监测、波形、通道与数据、频谱、肌肉协同、SD 记录、康复训练、佩戴适配、HDC 自学习、虚拟手映射和机械手控制。页面切换由统一路由管理，离开机械手页面会停止机械手输出。

MPU 负责虚拟手整体姿态和掌部旋转，肌电负责动作/手势类别和关节姿态映射。机械手的六路 PWM 由 PL 输出，PS 只下发经过标定和保护检查的目标。

## LCD 使用流程

1. 上电后进入实时监测；先完成静息校准和佩戴适配。
2. 进入 **HDC 自学习**，为每个类别完成三轮采样和两轮验证；类别验证达到现有门槛后才能用于稳定跟随。
3. 进入 **设置 → 虚拟手映射**，选择自定义类别，选择预设，再按关节滑动或微调，点击 **保存**。
4. 返回监测页，点击 **来源 MLP / 来源 HDC**。未映射、未验证或超时的自定义类别显示等待/未映射状态，虚拟手回到放松姿态。
5. 机械手控制单独进入 **机械手** 页面，完成六轴标定、保存和动作映射后再明确启用 HDC 联动。标定过程中会同步驱动机械手；停止、离页、通信丢失和看门狗都会关闭输出。
6. 康复训练提供单动作和四动作组合任务，可设置次数、保持和休息时间，并记录完成率、稳定性、响应时间和肌肉协同相对用力变化。

## 数据与分析

- LCD 波形页显示单通道原始或最终处理后的有符号波形，支持时窗、暂停、自动/固定量程和零点设置。
- 数据页显示八通道 MAV、门控阈值、动作、疲劳状态、缺口和配置状态。
- 频谱页使用处理后信号的 2048 点 FFT，显示选定通道频谱、峰值、MDF 和相对功率；频谱自动归一化并保留顶部余量，避免冲顶削顶。
- SD 记录同时保存同序号的 raw 和最终 processed 八通道数据，并保存动作标签；PC 工具可导出 CSV/JSON。
- 肌肉协同页显示 NMF 系数、活动条和趋势；疲劳页使用 PL FFT 的 MDF/能量趋势，结果用于训练反馈，不作临床诊断。

## 构建与验证

目标器件为 `xc7z020clg400-2`，Vivado 2025.2。常用命令：

```powershell
powershell -ExecutionPolicy Bypass -File build/build_all.ps1 -SkipBuild -SkipBoot
cmd /c "cd sw/ps_uart_print && build.bat --pl-control"
powershell -ExecutionPolicy Bypass -File build/boot/build_pl_control_boot.ps1
```

当前匹配启动镜像：

- 文件：`build/boot/BOOT_20261026_HAND_CONTROL_HDC_DYNAMIC_V13.BIN`
- SHA256：`edeede249706ec21601d9464f0901d9376e54350dada31bc2400de289d07ef55`
- 大小：5,086,684 字节

V13 复用了 V12 已验收的 PL 位流、XSA 和 FSBL；G1–G4 硬件门禁通过，BOOT 已核对 PL 分区、2 个应用加载段和 3 个 FSBL 加载段。主机验证包括 LCD 双分辨率、HDC 动态存储、PL 学习工作流、机械手控制、SD 记录和基础控制回归。证据集中在 `report/virtual_mapping_20261026/`。

当前未完成实板触摸、机械手接线后的连续运行和断电重启测试；生成的 BOOT 不会自动写入 SD 卡或下载到硬件。
