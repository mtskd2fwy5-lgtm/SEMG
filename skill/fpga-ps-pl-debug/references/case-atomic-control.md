# 案例：结果、目标和输出使能要分层

性质：控制代码、回归与用户观察的整理摘要。原设备为多路 PWM 负载，通道数和机械行程不作为通用要求。

**观察与处理**：旧版逐轴复位并关断，无法满足所有通道同帧启动并持续保持。改为禁用态暂存全组目标，完整校验后原子提交，STOP/复位清半包；验证同帧边沿、独立脉宽、超时和保持。来源：`report/hand_simultaneous_home_20261025/README.md`。

**使能误解**：复位后的保持态不是自动跟随态。识别和虚拟显示正常，仍可能因未显式启用、配置缺失或数据过期而无新输出。来源：`report/lcd_responsiveness_20261030/README.md`。处理是定位状态条件，不能默认解除保护。

**板接口极性**：后级反相光耦要求在板接口翻转引脚极性，内部脉宽含义保持正逻辑；有 RTL 和引脚网表核对。来源：`report/hand_pwm_inverted_20261029/README.md`。

**复用边界**：命令接受/PWM 变化不等于外部机构到位、卸力或力闭环。没有反馈时不能给出这些结论；该案例不要求其他系统使用相同 PWM 范围、保护阈值或页面模式。
