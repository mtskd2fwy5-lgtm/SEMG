# 案例：数值迁移须验证接口和独立参考

性质：代码/日志整理摘要。原工程将数值计算迁入 PL，处理器仍负责事务调度和结果消费；不能把核内计算迁移写成完全脱离处理器。

**关键观察**：位宽/符号、舍入、共享算子次序、配置代次、缓存和多字快照都影响等价。共用生成器的 Python/C/RTL 逐位一致仍可能共有算法错误。

**处理与验证**：写清整数与接口合同，覆盖边界、复位、背压、快照、过期和回绕；用迁移前浮点轨迹及独立物理算例补充共同生成器验证。姿态核在该组 13,528 样本/32 次复位中，矩阵元素最大差约 0.00220、角度最大差 1°；这是指定轨迹，不是全状态最坏误差或板端时延。来源：`report/imu_pl_20261028/README.md`、`report/imu_pl_20261028/float_comparison.json`。

**相关定点坑**：旧缩放将选定低幅 FFT 输入约 99.74%–100% 量化为 0/-1；调整后对选定活动片段进行浮点对照。IIR 满幅测试后零输入曾残留偏置，采用保存小数误差等方法修复。来源：`report/fatigue_20261025/README.md`、`report/line_filter_20261021/validation.md`。

**复用边界**：保留小数、输入增益或门限必须从自己的动态范围推导，不照抄案例缩放。数值验证不等于应用识别/检测有效性，更不等于实板验证。
