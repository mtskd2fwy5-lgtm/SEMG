# 可复用案例记录

案例性质：原始交互摘录 / 依据代码与日志的整理摘要（明确选择，不混用）。

| 字段 | 填写内容 |
|---|---|
| 场景与输入 | 使用者问题、器件/工具、输入接口/格式、期望输出 |
| 失败或观察 | 可复现触发条件；现象与推断分开 |
| 用户提示词 | 真实摘录及来源位置；无原文则标缺失 |
| 模型回答与纠错 | 可见回答、被证据否定的判断及修正；不补写历史 |
| 实施 | 变更范围、保持的合同、源文件/产物标识 |
| 验证 | 命令、参考、测试集/范围、结果、日志/哈希 |
| 已验证效果 | 明确是数值一致、仿真周期、host交互还是板上测量 |
| 可复用方法 | 陌生队伍应提供什么、执行什么、得到什么 |
| 失效条件 | 换器件/协议/算法时哪些假设要重新验证 |

输出结论示例：“在上述条件下验证了【观察结果】；【未覆盖范围】不由这组证据推出。”
