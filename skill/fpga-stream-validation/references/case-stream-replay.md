# 案例：先查连续性，再解释波形

性质：代码与记录分析整理摘要。原系统为 ADC→处理→FIFO→DMA→文件；业务数据是肌电，但故障机制属于流式工程。

**已定位故障**：记录开头出现序号倒退，前 359 帧在第 512 帧起逐字重复。FIFO 容量相当于 512 帧，启动记录仅复位 DMA 读侧而未协调 PL 写侧，导致旧数据回放。

**修复与验证**：正常模式切换保持运行 DMA，真正复位协调 FIFO 两端及各时钟域释放；区分正常回绕、前跳、重复、倒退和半圈歧义。重复/倒退终止记录，不把倒退算成大量正向丢帧。来源：`report/line_filter_20261021/validation.md`。

**另一观察**：无数字触轨仍存在局部异常；某路在特定放松片段的 RMS 约为常规片段的十余倍。原因未由记录唯一确定，不能直接认定断路。来源：`report/emg002_20261030/quality_report.md`、`report/emg002_20261030/quality_metrics.json`。

**复用边界**：重复长度与缓冲深度的对应是定位证据，不是看到重复就能断言单侧复位。序号不能还原故障期间真实时间；模拟异常不能单靠数字波形诊断。独立 CSV 工具验证的是格式、计数与数值，未包含二进制设备解码器。
