# Skill Package Draft

This directory will hold reusable engineering notes for the project.

## Purpose

Capture a repeatable workflow for:

- board bring-up
- ADS1299 capture validation
- signal preprocessing verification
- model training and comparison
- FPGA/PS integration checks
- report generation and demo preparation

## Planned Contents

- `workflow.md`: step-by-step build and verification process
- `checklist.md`: bring-up and debug checklist
- `baselines.md`: reference data formats and baseline metrics
- `prompts.md`: reusable prompt patterns for data analysis and report drafting

## Rules

- Keep file names ASCII only
- Record inputs, outputs, and validation results for every step
- Prefer scripts and measured data over prose claims
- Keep the workflow independent from a specific board revision when possible
