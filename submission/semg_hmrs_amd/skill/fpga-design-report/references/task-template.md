# 可直接使用的 FPGA 报告任务模板

## 输入

```text
报告用途/读者、赛道或评审规则（若有）：
最新模板/用户修改稿、章节与篇幅：
目标器件/工具、系统输入输出：
RTL/HLS、处理器/主机、板级接口的实际分工：
架构选择、基线/优化目标：
数值/功能、资源、时序、吞吐与延迟证据：
复现入口与产物：
尚未验证的范围：
```

## 提示词

> 使用 `$fpga-design-report` 基于以上实际实现和证据写报告。沿用用户框架与文风，清楚解释输入输出、并行/分时、存储、接口和 RTL/软件职责。量化比较注明器件、工具、约束、阶段和测试条件；将仿真、静态时序和实板测量分开。正文面向读者，内部数据代号移入证据索引。突出有依据的设计收益，不虚构未测性能或应用效果。缺少证据处明确留待核实，不编造数值和交互记录。

## 验收输出

稿件与证据对应；图中文字在报告最终版面可读；每项资源/性能结论有比较基线与范围；复现命令指向已有入口。实际文档导出后检查最终页面，不以 Markdown 文本或渲染成功代替版面验收。
