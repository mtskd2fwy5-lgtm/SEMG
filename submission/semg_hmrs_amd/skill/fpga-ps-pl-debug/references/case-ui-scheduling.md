# 案例：UI 回归和目标板性能分开

性质：实际固件 host 渲染、调度测试与用户现象的整理摘要。问题包括小字散点、频谱冲顶及所有页面/触摸变慢，可能涉及不同层次，不能统一归因。

**方法**：复用真实绘制代码，核对字模、像素格式/颜色、量程/bin 与帧缓冲所有权；用已知输入和两种分辨率测试全帧/增量、导航及失效状态，而非另做模拟界面。

**已定位代码行为**：显示前连续运行多个后台评分块，且 ACK 可触发重绘。改成显示优先、小块续算和基于目标计时器的累计额度，ACK 与可见变化分开。生产 worker 的续算/额度/回绕与双分辨率回归通过。来源：`report/lcd_responsiveness_20261030/README.md`、`report/lcd_responsiveness_20261030/cpu_test.log`。

**验证纠错**：块变小时，同调用次数不再代表相同计算量。吞吐测试保持等量计算，额度/公平性另测，不能删除原失败断言放行。

**复用边界**：单块仍可能超过剩余额度，不能宣称硬实时上限。未实测该轮板端 FPS 增幅，host 通过不能证明速度提升；静态页内容切换率为 0 也不代表面板未扫描。
