# 可直接使用的联调任务模板

## 输入

```text
器件/处理器或主机、工具、硬件与软件版本：
期望行为与实际行为、最小触发步骤：
源结果、消费者收到值、显示/目标、引脚各自现象：
寄存器/共享内存、协议位宽与字节序：
时钟/复位、快照/代次、命令和 ACK：
DMA/缓存、轮询/中断/主循环节拍（若有）：
使能、停止、超时、数据新鲜度与配置条件：
已有日志、测试和可执行范围：
```

## 提示词

> 使用 `$fpga-ps-pl-debug` 排查以上问题。沿数据生产、传输、接收、目标下发、输出和外部反馈分别取证，先找首次不一致，再修改。检查多字快照、缓存/所有权、CDC/复位、ACK 和使能状态，不自动绕过保护。含显示时复用真实固件渲染并区分主机测试与目标板计时。交付定位证据、针对性修复和正常/故障/切换回归，不把命令成功说成外设物理到位。

## 验收输出

提供端点/状态时序表、触发步骤、首个错误层、对应代码/观测、修改及复测。统计采样、计算、传输、软件调度和显示延迟时分别标明起止点。不要求新工程采用案例的轴数、地址、租约或页面规则。
