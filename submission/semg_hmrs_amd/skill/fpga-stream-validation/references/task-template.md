# 可直接使用的流式验证任务模板

## 输入

```text
工程/数据路径及实际运行版本：
源→跨域→缓冲→传输→消费者的链路：
时钟、采样/更新速率：
通道/打包顺序、字节序、位宽/符号/缩放：
帧头尾、序号/时间戳含义及回绕：
握手、FIFO 深度、DMA/缓存所有权（若有）：
启动、模式切换与故障复位行为：
数据是哪一级处理结果：
观察到的异常/大约位置：
可用参考、测试模式与允许测试范围：
```

## 提示词

> 使用 `$fpga-stream-validation` 核对以上链路。先保留原文件并检查格式、帧和序号，再从源到消费者定位首次异常；区分回绕、缺失、重复、倒退与未知。用实际处理合同对照参考，不能按文件名猜处理链或静默删坏段。按需使用已有计数/冲激/边界/背压测试。输出异常位置、分层证据、修复与验证，以及无法从现有记录恢复的信息。

## 验收输出

记录源文件哈希、有效/异常区间、原始序号、数据级与标度、各观测点结果及修复后同条件复测。缺少序号或格式不适配时说明限制，不强行套用整数 CSV 脚本。处理结果正常不等于前级模拟链或物理采样正常。
