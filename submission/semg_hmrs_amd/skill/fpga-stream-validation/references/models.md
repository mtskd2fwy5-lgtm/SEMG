# 数据驱动模块的验证边界

仅在流数据用于识别/估计模型时使用。先冻结输入特征顺序、位宽、缩放、窗口/步长、量化/ROM、输出类别及后处理；不要把浮点离线输入直接当板端输入。

区分三个任务：冻结模型回放、新建探索模型、重新训练部署。比较实现时用同一合同和输入；比较应用效果时按完整采集批次或独立试次留出，重叠窗不能随机跨训练与测试。归一化、选择和调参只看训练侧。

报告逐类支持量/混淆与拒识，模型分数不直接解释为正确概率。高分错类应检查数据分布、标签和特征一致性，不先放宽阈值。含未知变化点的混合标签段不猜真值，单独分析或排除评分。

恢复的历史验证结果不能当当前环境重新验证。新模型/配置切换应与流代次绑定，清理旧状态；输出端按实际使能/新鲜度规则处理。

来源：[跨采集条件模型案例](case-model-contract.md)。应用域可更换；案例数值不代表其他模型或设备效果。
