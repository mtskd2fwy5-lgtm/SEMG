# Submission manifest

This tree is generated by `tools/assemble_submission.ps1` from the repository
working tree. It contains source and reproducibility inputs, not a snapshot of
the developer machine.

Included:

- PL RTL, PS bare-metal firmware, HDL/C/SystemVerilog tests and Python/PowerShell tools.
- Canonical Vivado block design, managed-IP XCI files and board constraints.
- Bounded model/metric inputs needed by the tests; no private raw recordings.
- Four reusable FPGA skills with scope, procedure, evidence and failure boundaries.
- Design report, AMD guide cross-check, AI-collaboration evidence index and routed HDMI release evidence.

Excluded:

- `.Xil`, Vivado/Vitis workspaces, generated DCP/XSA/bitstream/BOOT files and compiler caches.
- Raw sEMG recordings, expanded wave exports, local logs outside the selected evidence set and private paths.

The package is valid only together with the stated tool versions, board wiring
and third-party notices. Passing a host or RTL test does not claim physical
board validation.
